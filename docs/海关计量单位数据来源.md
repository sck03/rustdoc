# 海关计量单位数据来源

2026-11-07 从[中国国际贸易单一窗口](https://www.singlewindow.cn/)的[计量单位（海关）参数查询](https://www.singlewindow.cn/#/parameterDetail?pqcode=CusUnit&flags=1)取得完整 `CusUnit` 目录，共 127 项。官网说明适用于货物申报、集中申报、减免税、快件通关、公自用物品、加工贸易、跨境电商等业务应用。

## 来源与复核方法

- 官网公开前端 `js/app.d38b92ef.js`、`js/blueTableList.0378906a.js` 定义参数目录及分页查询；未使用登录凭据。
- `POST https://www.singlewindow.cn/access/ui/SW-SITE-FRONT/Param001` 返回目录定义，选择 `pqcode=CusUnit`。
- 按官网请求格式，以 `Head={}`、`Data` 为 JSON 字符串，向 `/access/ui/<毫秒时间戳>/Param002` 查询 `paramName=CusUnit`，`pageNo=1/2`、`rowsPerPage=100`，筛选字段及值为 null。
- 两页均返回 success，`totalRows=127`、`pageSumCount=2`，分别包含 100/27 项；合并核对代码唯一、行号连续、无筛选，保留 `UNIT_CODE`、`UNIT_NAME`。
- 官网响应没有公布数据集版本号或生效日期；本文件记录的是 **2026-11-07 查询快照**，不能把参数定义的修改时间当作目录生效日期。后续更新需重新全表核对，不能只更新少数可疑编码。

唯一生产数据文件为 [`customs-units.tsv`](../crates/export-doc-domain/resources/customs-units.tsv)，按代码排序，UTF-8、LF；SHA-256 为 `25e81fd2a9bca39aab74a709b87f4815fbf232677d7b456164b010ea61d215bf`。运行时由 Domain 内嵌并一次建立索引，不联网、不读取宿主文件或维护另一份转换表。

HS 年度导入沿用同一个转换入口，第一/第二单位分别解析后组合；例如 `132` 与 `35` 为“本/千克”。数字前导零不影响已知代码；未知代码保留原文，137/138 不再猜测为体积单位，已有中文及自定义单位保持。带正负号、小数点的文字不作为合法代码转换。导入预览继续不写正式数据，旧业务记录不会被程序启动自动改写。

本项只核验海关 `CusUnit`，不把产地证英文单位、包装单位、原报检单位或数量标准代码视作同一代码体系。现有单一窗口参考目录没有另一份 `CusUnit` 映射，无需复制或修改那些独立资料。
