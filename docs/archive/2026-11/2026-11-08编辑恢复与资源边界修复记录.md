# 2026-11-08 编辑恢复与资源边界修复记录

本批从 `4eddc09b` 开始，修复项目审查中确认的编辑恢复、预览取消、任务收尾、PDF 并发与备份轮询问题，并按未正式部署、不保留旧版兼容的要求移除数据库快照 WebDAV 流程。数据库继续使用 schema 14，没有迁移链或依赖升级。

## 实现边界

- `useServerDraftSync` 提供显式采用服务器版本的操作，发票和付款共用；加载成功后统一更新草稿、保存基线和编辑状态。失败保留本地修改，切换记录或卸载后的响应不应用。快照使用记录自身 ID，避免路由 ID 掩盖不同记录；保存期间继续输入的草稿仍保留。
- 发票保存模型将明细规范化及精确合计分离为独立投影。界面按明细数组、汇率和币种复用投影，修改表头不扫描全部明细；保存边界仍完整规范化。没有引入浮点金额算法、全局永久缓存或新持久化状态。
- 短期预览区分过期请求与当前请求的取消。当前请求收到 `AbortError` 后释放忙碌状态，允许重试；过期请求不能清理新请求状态。
- 备份计划和任务查询发生错误后停止周期轮询，沿用统一查询策略处理有限次数的暂时故障重试。界面显示真实查询错误，提供重试和停止跟踪；终态识别复用任务模块。
- 装箱 PDF、OA 审批单和受限材料投影接入现有共享渲染准入，限制覆盖排版与编码，等待不占数据库连接。渲染结束先释放名额，再进行授权复核或输出发布。
- 任务终态发布、写锁等待、SQL 和保留清理共用独立的 30 秒操作作用域，执行任务取消不取消终态登记。写锁改为检查取消与期限的获取方式；失败继续关闭任务入口并保留恢复信息。文件补偿和提交后清理仍使用已有独立预算，不强杀提交线程。
