# OA 操作手册入口

更新日期：2026-11-13。适用于业务协同平台 Full、当前 schema 18。正式团队使用网页/Docker + PostgreSQL 18；Full SQLite 便携包用于培训与测试。文件设置、容量与备份对象要求见[文件存储与容量管理](./文件存储与容量管理.md)。

| 读者 | 可维护正文 | 下载与打印 |
| --- | --- | --- |
| 管理员 | [OA 管理员手册](./manuals/OA管理员手册.md) | [管理员 PDF](./manuals/OA管理员手册.pdf) |
| 员工、审批人、办理人 | [OA 用户手册](./manuals/OA用户手册.md) | [用户 PDF](./manuals/OA用户手册.pdf) |

管理员手册覆盖组织任职、账号关联、权限方案与范围、表单和流程规则、仿真发布、定时启用、代理交接、异常处理及备份；包含请假、报销和样品寄送三个操作实例。

用户手册覆盖登录和身份选择、草稿、附件、提交、退回重提、审批、实际办理、资源交接、审批单下载及常见问题。

两本手册的 Markdown 是正文源，PDF 由 `node scripts/generate-oa-manuals.mjs` 生成。界面截图必须来自当前匿名验收；更新后核对全部 PDF 页面，不单独修改 PDF 内容。生成和检查入口见[脚本说明](../scripts/README.md)。

权限和流程的当前事实见[架构事实](./当前架构事实.md)；部署和停机恢复见[服务器备份迁移与恢复指南](./服务器备份迁移与恢复指南.md)。历史验收见[归档索引](./archive/README.md)，不作为当前操作步骤。
