# 产品架构与文档总览

桌面采用 Tauri 2 + React + Rust + SQLite，网页/Docker 使用同一 React + Rust HTTP + PostgreSQL 18。先读[当前架构事实](./当前架构事实.md)，再按任务选择下列文档。

正式单机产品为单证版（主力）和业务员版（个人外贸工作台）；多用户 Full 承接完整业务、行政人事和审批。按 2026-09-30 用户要求，本地另可单独构建 Full + SQLite 测试便携包，用于免部署检查完整界面、公告通知和 OA 登记流程，详见脚本入口。
