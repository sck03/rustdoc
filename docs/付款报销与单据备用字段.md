# 付款报销与单据备用字段

付款报销与发票分别保存内容。“发票号／业务参考号”用于人工核对，不会自动带入或修改报关明细；同一中文品名、不同成分的报关行可在付款中合计填写。

## 付款填写

基础信息填写付款单号、参考号、付款／收票日期及收付款单位和银行账号。默认展开的付款业务信息填写部门、项目、贸易方式、退税率、货物品名、数量、单位、出运国家、出运日期及备注。数量和退税率保留自由文本，允许按票面填写附加说明或“其他”，不参与报关数量及税额计算。

| 工厂付款单票面 | 表单／设计器字段 |
| --- | --- |
| NO. | 付款单号 |
| 业务部门／名称 | 部门 |
| 出口发票号 | 发票号／业务参考号 |
| 货物名称及数量 | 货物品名、数量、数量单位 |
| 出运国别、收证日期 | 出运国家、收票日期 |
| 贸易方式、退税率 | 同名字段，可作为表格勾选条件 |
| 收款单位、开户行及账号 | 收款方、银行、账号 |
| 小写金额／人民币大写 | CNY 金额／金额换算中的人民币大写 |
| 其它票面内容 | 付款备用字段 |

## 备用字段与模板

- 发票基础信息中展开“发票备用字段”，填写表头补充内容。
- 商品明细的“备用 1—10”分别随每行保存，用于款式、包装或客户要求等附加内容。
- 付款业务信息中展开“付款备用字段”，填写本次付款的附加内容。
- 每类固定十项，每项最多 500 字；未填写时输出为空，三类字段不相互同步。
- 在可视化设计器的“单据备用字段”“明细备用列”“付款备用字段”分组中选择。单据字段可填入普通表格，明细备用列用于循环明细表。显示标签可改成“采购合同号”“审批说明”等实际用途，无需改变字段编号。

建议同一套模板为备用编号约定稳定用途。备用文本不代替金额计算、审批状态或公司／部门授权归属。

## 数据基线

正式空库基线为 v19。按本项目尚未投产的规则，不为旧开发库增加兼容迁移；需要保留的数据应先备份，验证新版本时使用独立空数据目录。开发和验收不会自动删除已有业务库。
