# 2026-11-24 权限摘要与财务接收状态

## 实现

- 权限来源直接组合共享 Dialog、CollapsibleSection 和 InlineNotice，移除账号模块对行政 UI 导出别名的依赖。账号摘要样式随组件加载，避免页面尚未加载行政样式时退回默认 dl／p 排版。
- 摘要按单位、产品版本、权限来源和 OA 范围分组；产品名称复用中央展示目录，授权日期仅在存在时显示。删除重复解释段落及四项“关闭：无”；实际受限功能和限制来源仍显示，操作明细默认折叠。
- 通知展示拆成卡片与纯展示模型。报销当前状态 Approved 显示“待财务接收”，HandedOff 显示“已财务接收”；审批中、驳回、取消等不显示接收标签。原审批事件、申请标题、通知时间和已读状态保留。
- 卡片网格沿用 300px 最小宽度并保留空列，单张卡片不铺满整行，窄屏自适应。保留审批文案和右侧标签；“财务接收范围回归”仅为隔离测试的申请标题，未作为产品固定文案。
- 无后端、数据库、API、依赖或账号权限调整。财务接收继续表示资料交接，不代表记账或付款。
