# Tauri + React + Rust 功能迁移核对表

> 2026-09-20：原版 ExportDocManager_CS 为逐页对照来源。React 页面直接复用；每批集中联调，最终统一门禁。旧 Slint 页面记录退役，后端路由覆盖不等于用户操作等价。

2026-09-20 补充源码盘点及完整逐页台账见[《Rust 与 C# 后端功能差距及修正方案》](./Rust与CSharp后端功能差距及修正方案.md)。报表按用户确认继续使用 **krilla + PDFium**；优先修正 HS 联网数据语义、模板目录/渲染衔接及报表模型。该文区分确定缺失、行为差异和已有实现待验，不将本表的模块存在视为原版功能完成。

| 批次／页面 | 原版界面 | 共用 Rust 能力 | 本轮核对要求 |
| --- | --- | --- | --- |
| 桌面启动、登录、退出 | 恢复原版 bridge 与 Tauri 壳 | SQLite、会话、HTTP、关闭任务 | 真实窗口、令牌隔离、空密码单机登录、退出释放 |
| 工作概览、待办、任务中心 | 原版页面保留 | dashboard、worklist、tasks | 真实响应、列表、状态与导航 |
| 发票、商品明细、付款、查询 | 原版五页签及表格保留 | records、workflows、reports | 新增／修改／冲突、草稿、报表与实际 PDF |
| 客户、供应商、商机、跟进 | 原版目录和对象详情保留 | crm、sales、related_records | 保存、并发、范围权限、导入导出 |
| 组织、人员、通讯录、行政 | 原版页面保留 | organization、personnel、office | 组织联动、隐私权限、预约／交接 |
| 模板与设计器、单据包 | 原版 V3 画布保留 | report_templates、report_assets、document_packages | 模板资源、发布、预览与输出一致 |
| 邮件、汇率、HS、OCR、Excel | 原版工具页保留 | 独立能力 crate 及 engine 适配 | OCR 已实测 Rust PP-OCRv6 + ONNX；文件选择、预览、识别、结果复制和缺资源提示已接通 |
| 单一窗口、装柜 | 原版页面保留 | single_window、packing | 持卡机／回执样本、生成输出与版本 |
| 权限、日志、设置、备份、恢复 | 原版管理页保留 | accounts、audit、settings、maintenance | 敏感字段、数据库错误、失败恢复、清理 |
| 关于、更新、部署 | 原版入口保留 | Tauri updater、Rust 发布脚本 | notices、签名信任、包内容、跨平台运行 |

报表模板已修复原版“新建空白模板”流程：空 `contentHtml` 由 Rust 生成 V3 A4 草稿，个人模板可打开可视化设计器、添加文本并保存版本，发布／复制／预览链路已回归。仍未完全等价的边界是原版高级 HTML 模板、普通表格 Grid、条件块、复杂明细分组／汇总、全部图片资源授权与多模板输出；Rust 当前原生排版器明确拒绝未实现结构并保留原稿，不静默降级。

以上“保留／复用”只描述代码，不表示所有操作已通过真实联调。本批验证结果和明确缺口在《程序改进重构进度文档》记录；Docker、PostgreSQL 现场、其它操作系统和官方单一窗口均须各自环境验收。
