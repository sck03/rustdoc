# 2026-11-28 异步草稿与备份性能修复

本批承接全项目审查，按用户授权实施确认的问题、修正文档、清理已失效输出并交付 main。只运行受影响的必要检查，不执行完整 workspace、全部前端或跨平台验收。数据库保持 schema 19，API 原生定义、生成客户端和依赖版本未变。

## 实现

| 范围 | 根因与结果 | 职责边界 |
| --- | --- | --- |
| 邮件模板 | 客户 A 的迟到响应不再覆盖 B；搜索、变量载入、预览分别取消，输入/客户/模板/客户端/页签变化使旧结果失效，迟到预览不再触发跳转。手工样例与客户变量分开保存，切客户保留手工草稿 | `useEmailTemplatePreview` 管理读取生命周期，页面只组合展示与操作；复用现有取消控制器 |
| 容量策略草稿 | 保存期间输入的新值保留，下一次保存使用服务端返回的新版本；成功提交后先更新查询基线，再刷新其它数据 | `useStorageGovernance` 处理提交快照和版本推进，界面不再无条件清空草稿 |
| 告警展示 | 接入后端已有的最近 100 条告警，按时间倒序展示区域、状态、原因与处理方法；低频历史默认折叠 | 使用现有表格、折叠分区、日期格式和设计令牌，没有新增样式体系 |
| 容量采样 | 采样及策略保存共用可取消、最多 30 秒等待的独立锁；读缓存检查策略版本，事务内再次核对策略并从当前状态生成转移告警 | 外部磁盘探测仍在写事务外；状态版本单调推进，不重复发布同一次状态转移 |
| 备份配置 | 外接盘/网络盘身份探测移到调度锁和数据库写事务之前；写入时核对当前计划版本与登记介质，使用仓库时再查介质 | 慢介质不占用普通业务的数据库写入协调器；不静默登记替代设备 |
| 远端仓库 | WebDAV 使用独立 `readers/` 控制目录；每次 GC 检查仍实时读取保护标记。受保护写入/读取会话复用一次有界对象枚举，写入和删除同步索引 | 公用 `remote_index` 负责名称快照；S3 保留服务端分页；所有权/会话检查仍在操作前后执行 |
| 恢复点列表 | 依真实时间点倒序，随机 ID 只用于同时间排序；摘要最多 10,000 条、最长复用 60 秒。每次请求重新核对保护及当前 COMMIT 名称集合，配置或集合变化立即重建 | 缓存只供显示，不替代导出/恢复/核验；不保存明文凭据或业务内容 |
| 便携导出 | 从实际输出的密文解密并复用完整清单校验器；同名对象仅输出一次，完整文件摘要和最终统计通过后才输出 COMMIT | 名称数受导入索引预算约束，明文缓存上限 16 MiB/64 项并在释放时清零；超出缓存的共享块仍可重读用于文件摘要 |
| 仓库初始化 | 远端刚取得的 `writer-session` 不再被判断为已有业务对象 | 不放宽其它非空仓库保护 |

WebDAV 读取保护目录调整面向尚未生产部署的现行实现，不提供旧程序混用或自动搬移旧保护标记的兼容链。发现根目录旧读取保护时明确拒绝，需先停止旧程序并核对中断保护。真实存储库、备份和用户资料不由本批清理自动转换或删除。

## 必要验证

- Engine 定向测试覆盖仓库、容量并发、计划/恢复和 WebDAV/S3 协议，共 14 个不同测试通过。包含真实本地 SQLite 服务、受管目录、隔离 HTTP 协议夹具；没有连接厂商存储。
- 仓库新增回归证明：同一数据块被两个文件共享时只读一次并只输出一帧；有效密文包裹的不一致文件摘要仍被拒绝；时间偏移不同的恢复点正确倒序；连续分页不重复解密同一摘要；读取保护和丢失写入权继续阻止清理/枚举。
- `test_async_draft_ui.mjs` 使用真实 React 组件和模拟 API，在受管 Chromium 验证客户乱序、手工草稿、迟到搜索/预览/导航、策略保存期间续编及历史告警。
- 现有 `test_email_template_workspace_ui.mjs`（5 场景）与 `test_storage_governance_lifecycle_ui.mjs` 通过，覆盖保存/历史/取消、任务回执恢复、刷新和独立复核。
- Web 生产构建（包含两份 TypeScript 检查）及样式治理通过；Engine `--all-features` 编译检查、Rust 格式和差异检查通过。

上述读取/枚举次数是回归断言，不是吞吐或 RSS 基准；未做全量 workspace、真实 PostgreSQL/Docker、实际 Tauri、厂商 WebDAV/NAS 故障注入、大仓库峰值及其它 OS/架构真机测试。已知 GLib 安全审计事项沿用独立治理，不宣称本批修复。

## 代码规模与交付

删除页面中重复的异步读取逻辑和便携导出预验证/二次取密文路径；新增职责独立的预览 hook、目录摘要与远端索引模块。源码总行数没有作为性能指标，新增完整性保护和定向回归按实际统计更新规模基线，保留单文件上限与原有后续增长额度。

当前计数为前端生产 90,170 行、Rust 原生生产 126,219 行、原生测试/示例 39,502 行、通用自动化 33,232 行。增长来自取消与完整性边界、受保护索引和相应回归，未通过压行或扩大单文件限制掩盖复杂度。
