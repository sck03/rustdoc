# 2026-11-11 模板、预览与 CI 优化记录

## 变更范围

- 单一窗口产地证改用独立三表 Excel，包含基本资料、商品明细、生产企业；以编号关联工厂。英文名称／地址分列，FOB 独立输入，原产国整票默认／逐行覆盖，中文单位可由英文单位换算。导入后覆盖通用发票的 CHINA／PCS／件默认值；未声明原产国或单位时保持空白，显式中文单位优先。
- 发票模板统一深蓝表头、浅色录入区、细分隔线、数字格式与冻结行，去除预设真实公司名称并修正 CONSIGNEE 拼写。保留工作表、固定坐标、合并区域与六个合计公式。发票目录新增“下载报关 Excel 模板”。
- 产地证资料通过原生契约生成专用预览／来源补充 DTO。继续复用 Excel 识别和行计算，来源保存后回读 COO/ACD，保留逐行工厂、联系人、精确 FOB。校验重复／未知工厂、错误日期、字段长度与 FOB 边界。普通发票来源不再把出口商当作工厂，不把 CIF 等金额当作 FOB。
- React 新建资料分开编号、文件／识别方式、下载和创建动作。文件选择框显示当前待导入文件，清除后同步恢复空态，不重复显示文件名。下载共用桌面选择路径、任务等待、网页票据和作用域取消。RCEP 商品允许编辑生产商保密字段。
- 启动样式从 index.html 移到 startup.css，保留 Tauri 默认 CSP 处理，避免启动内联样式的 nonce 干扰报表 srcdoc 样式。
- 自动 quick 仅跑按变更范围选择的 Rust 库单元／契约、桌面组合检查和前端回归。完整集成、doc-test、全部特性、OA HTTP/React、跨平台／容器归手工 full。full 不再同时执行 quick Rust core；打包复用前端构建，Cargo 编译缓存增加可更新的源码键。
- 删除无当前入口的旧 web-runtime smoke 专属场景链、旧 PDF 指标比较链及仓库初始化脚本。当前 Chromium 公共工具、原生 PDF/桌面验收、专用 UI 场景和 updater 发布脚本保留，防止按“未自动引用”误删有效手工入口。

数据库仍为 schema 17，未改 SQL。Excel crate 直接声明锁图已有 serde，无依赖版本升级；API 文件由正式生成器输出。

## 字段依据

2026-11-11 核对单一窗口[海关原产地证书报文](https://www.singlewindow.cn/#/documentDetail?cid=COO-coo-chart&ctype=1)及所附 XSD／客户端导入说明。生产企业申报名称、组织机构代码、联系人、联系电话，与证书生产商英文描述分别处理；中／英文单位业务申报必填，商品原产国适用 RCEP。详情和证种差异见[Excel 填写说明](../../单一窗口Excel导入说明.md)。
