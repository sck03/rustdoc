# 2026-11-26 组织删除、账号单位菜单与 Excel 默认资料

基线：`3de7dca4`。按用户要求修复默认组织删除、调整单位入口并精简 Excel 设置，仅执行受影响范围的验证。此前终身／定期／试用授权显示修复保留。

## 组织引用与账号归属

通用记录保存附带创建者的 `companyScope`／`departmentId`。原组织删除查询把公司、部门、权限方案和单位身份记录中的这类范围字段全部视为成员关系，导致管理员迁出后，“本公司／综合部”仍被目录记录和全局内置方案误报引用。回归先复现原实现的 409，再验证修复。

Storage 查询现在区分真实关系：公司引用上级公司，部门引用所属公司／上级部门，单位身份引用目标公司，单位权限方案按规范化表的 `owner_unit_id` 引用单位。账号、单据和人员历史任职继续保护实际引用。无数据库结构或迁移变更，SQLite 与 PostgreSQL 复用同一查询构造。Engine 原有版本、权限、事务和删除次序继续生效。

`admin` 的管理权限来自角色和授权。公司／部门用于主身份组织归属，并影响业务默认值与单位上下文；只选公司表示未归属具体部门，两者为空表示主身份未分配组织。管理员迁出且没有实际引用后，先删除部门，再删除公司；存在真实单据、人员或单位方案时仍须处理引用，不能强行级联删除。

## 账号菜单

账号按钮保留姓名及“账号 · 角色”，单位名称只在展开菜单的“单位身份”分组中显示；删除顶栏独立下拉框。当前身份有勾选标记，单身份也可查看名称。复用共享 DropdownMenu 的键盘、焦点及设计令牌，通用菜单支持分组／单选语义，长单位名换行且选项区域可滚动。切换错误显示在顶栏下方。

展示由 AccountMenu 组合，切换仍调用既有 `useUnitContextSwitch`，沿用未保存修改确认、请求取消、会话及缓存隔离。专项通过真实内联账号编辑验证中文草稿的取消保留、确认切换和单次请求；不再通过自动化选择被模态窗口遮挡的旧顶栏控件。

## Excel 出口商默认资料

- Excel 已提供出口商中文名时原样保留；只有空白名称才取当前单位在“组织与任职”中的公司名称。预览中的发票与出口商候选保持一致。
- 空白导入模板／订舱托单使用相同公司来源；未分配公司时留空。公司名称实时读取，不从全局出口商目录猜测，也不把公司名称写成永久绑定。
- 既有发票导出使用发票快照。发票可重新选择出口商档案，由现有表单更新名称、地址、银行等资料并保存；默认值不会在保存时覆盖用户选择。
- 应用模块 `engine/excel/company_defaults.rs` 负责身份与单位解析，Excel 库只解析／生成工作簿。移除设置输入框、默认值、标签、分类及原生契约字段 `system.defaultTemplateExporterNameCn`，通过正式生成器同步 OpenAPI 和 Rust／React 类型；冻结契约只增加明确审阅的字段退役差异。
- 删除无生产调用的 `sole_exporter_name` 查询、适配接口和对应旧猜测测试。旧设置沿用现有 schema 投影去除退役属性，不增加兼容分支或重建数据库。
