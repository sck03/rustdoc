# OA 负责人兼任与节点配置

核对日期：2026-11-26。适用于当前 Full 的流程管理页面；七类 OA 的流程定义分别维护，统一移交接口不合并流程。

## 部门负责人同时是公司负责人

普通员工提交申请时，如果部门节点与公司节点解析到同一自然人，且“独立复核”为“允许兼任，逐节点记录”，程序保留两个任务。该负责人分别完成两次签署后，申请才能进入获批办理。

若节点要求“独立自然人”，同一个人不能承担重复复核。须给其中一个节点配置另一位具有相应业务权限和有效人员任职的责任人；同一人的另一个账号或另一单位身份也不能绕过自然人判定。

申请人为这位兼任负责人时，不能自行审批。部门节点的本人回避仅在既有条件全部满足、后续有独立公司领导审批时跳过；公司节点仍是本人时，提交会被阻止。程序没有“仅领导本人申请时自动使用备用审批人”的单独设置。

## 指定另一位审批人

1. 切换到申请所在单位，用有“流程管理”权限或账号管理能力的账号进入 **OA → 申请与审批中心 → 流程管理**。
2. 进入 **流程定义**，选择要修改的请假、加班、报销、出差、采购、人事或通用申请流程。
3. 选择 **节点图 → 步骤列表**，找到需要调整的审批节点。
4. 将 **责任人来源** 改为 **指定人员**，在 **责任账号（可多选）** 中选择另一位责任账号。账号须关联有效人员任职，并取得申请单位中该业务的查看和审批权限；负责人职位本身不授予权限。
5. 核对 **遇到申请人本人**、**独立复核** 和 **通过方式**。会签要求全部同意，或签只需任一人同意；这些选项决定实际签署要求，不应仅为通过仿真随意修改。
6. 点击 **保存当前流程**，进入 **仿真与发布**，用普通员工和兼任负责人分别核对样例，执行 **仿真并发布此流程**。按具体错误补齐人员、任职或权限。
7. 其他需要同样调整的流程分别保存、仿真并发布。

指定人员会成为该流程以后提交申请的该节点责任人，并不只处理领导本人的申请。已提交的申请继续使用提交时的流程快照；未完成的审批需要在申请详情或流程管理的任务入口使用 **移交未完成审批**，选择有效目标单位身份并填写原因。

## 移除公司负责人审批节点

在 **节点图 → 步骤列表** 中点击该节点的 **移除节点**。普通节点删除后，后续节点自动承接其前置节点，并去掉重复依赖。例如：

- 删除前：部门审批 → 公司审批 → 办理登记。
- 删除后：部门审批 → 办理登记。

草稿支持 **撤销／重做**。保存和发布前，检查后续办理顺序并重新仿真。最后一个审批决定节点不能直接删除；涉及排他分支目标、分叉／汇合配对或分支定义的节点会显示具体限制，须先调整相应关系。

移除公司节点并不取消本人回避。若部门负责人也要使用该流程申请，须留下可实际签署的独立审批人；仅留下“本人跳过”节点不能自动批准。

发布只影响新提交实例，历史审批记录和已提交申请不随节点删除而改写。本补充为当前操作说明；手册 PDF 的生成日期和修订范围以各手册自身记录为准。
