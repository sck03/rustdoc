# 系统设置分组与维护

> 2026-10-25 补充桌面运行目录迁移与软件更新规则。部署与存储以[当前架构事实](./当前架构事实.md)为准，执行证据见[进度](./程序改进重构进度文档.md)。

系统设置按任务分类。桌面、浏览器和容器共用界面；分类由产品能力过滤，配置仍由管理员统一维护。

| 分类 | 内容 |
| --- | --- |
| 运行与数据库 | 软件名称、通用导出目录、当前数据库连接；桌面端另有更新来源 |
| 单据设置 | 录入默认值、发票表头／商品明细／付款报销的字段名称、申报默认值 |
| Excel 导入 | 缺省出口商中文名、导入方案、单元格和列映射 |
| 汇率与币制 | 来源格式与网址、自动获取间隔、共享报价和常用币种顺序 |
| 邮件设置 | SMTP、发件人、单据邮件默认内容和收件人规则 |
| 备份与恢复 | 默认关闭的日常灾备、WebDAV／S3 异机副本、整机迁移、恢复与校验 |
| AI 服务 | 模型地址、名称、密钥及提示词 |
| 维护工具 | 日志管理、数据归属、发票清理、运行检查和问题诊断 |

报表模板、文件命名、PDF 合并和 ZIP 默认值继续在“报表模板管理”中维护。

日常业务邮件模板在“工作台 → 邮件中心 → 邮件模板”维护。设置分类、字段分组及维护子页会更新地址，可刷新或从功能搜索直接打开；未保存配置仍只保存在页面内存。

## 运行数据目录与桌面更新

桌面安装版在“备份与恢复 → 整机迁移 → 运行数据目录”点击“更换数据目录”，选择本机保存位置，程序在其下使用 `ExportDocManager_Data` 专用空目录并安排重启迁移。先保存业务草稿、等待重要任务完成，再退出并重新打开原程序。程序在源、目标实例锁内复制并校验，完成后主路径配置及其备份都使用新目录；旧目录保留封存标记和实例锁，不能继续打开为另一套空库。占用、中断或内容冲突时按错误提示处理后重新启动原程序，不删除迁移标记。原磁盘断开或已保存目录缺失时停止启动，应先连接原磁盘或恢复路径配置。便携版通过退出后复制完整程序目录迁移，目录清单及恢复边界见[路径审查清单](./运行目录与路径存储审查清单.md)。

桌面更新来源在“运行与数据库 → 更新来源”维护，保存后到“软件更新”页检查版本。检查和下载期间均可点“取消更新”，进入安装后不能中断。连接等待最多 10 秒、读取空闲最多 30 秒，检查总时限 30 秒、下载总时限 15 分钟；超时或失败明确显示未完成，不显示为已是最新版，也不会一直占用更新名额。取消或失败后可以重新检查。安装仍要求有效管理员会话及受信签名；便携版提示取得新便携包并保留 `App_Data`，不执行安装器更新。

## 单据设置

- 默认打开“录入默认值”，配置前 0—10 个备用列和明细预留空白行数。已有内容的列自动显示，每张发票可临时调整显示列。
- “字段名称”一次显示一组十项，桌面两列、窄屏一列。切换分组或设置分类保留当前草稿。
- “申报默认值”维护申报员、签证机构、领证地点等单一窗口默认项，与 AI 服务分开配置。
- 名称最多 40 字、同组不能重复，留空使用“备用 N”。保存后连接同一服务的账号共用；其他客户端重新进入或刷新页面读取。数据字段键保持稳定，已有模板的文字标题仍在设计器中修改。
- 发票表头、明细显示列和付款备用字段提供管理员快捷入口，打开对应分组；有未保存单据时先确认是否离开。菜单按当前产品和权限过滤；Administration 已不再作为单独桌面产品。

## 今日汇率与币制设置

“今日汇率”和本分类共用保存的来源、报价缓存及常用币种顺序，提供互相跳转的入口。先选择来源格式、填写网址和币种，再点“保存全部修改”；来源草稿未保存时，刷新和币种操作暂停，避免把旧来源的货币列表当成新来源。刷新成功会更新候选币种；暂时缺失的已选币种保留并提示，清空选择会明确显示未选币种，最多选择 15 种。

自动获取默认关闭。开启后可选 30 分钟、1 小时、2 小时、6 小时或 24 小时，保存即生效；服务端允许 30–1440 分钟。桌面程序或服务器运行时由单个后台工作线程调度，关闭页面仍会更新，退出程序则停止。关闭自动获取时，间隔作为共享缓存有效期，可保留既有的 1–1440 分钟设置。每 30 或 60 分钟通常属于低频请求，但是否允许仍取决于来源网站规则，不能仅凭间隔承诺不会限流。

进入页面会读取共享报价；手动刷新和后台获取共用缓存及互斥请求，同一来源一分钟内不重复抓取。网络失败时保留同一来源上次成功的报价，并显示过期状态、失败原因和下次重试时间；重试从 5 分钟逐步延长至 60 分钟，并遵守来源返回的更长 `Retry-After`。切换来源不会混入旧来源报价。缓存只在内存中，重启后重新获取，没有新增报价数据库或浏览器持久存储。

| 来源格式 | 可接受的数据 |
| --- | --- |
| 中国银行报价网页 | 默认 `https://www.boc.cn/sourcedb/whpj/`；按“货币名称”“现汇买入价”等表头定位，列顺序可变化，同币种保留最新发布时间 |
| 中国工商银行 | 预设官网 `https://www.icbc.com.cn/column/1438058341489590354.html` 对应的公开牌价接口，保留现汇和现钞买入／卖出价 |
| 招商银行 | 预设官网 `https://fx.cmbchina.com/hq/` 对应的公开牌价接口，保留现汇和现钞买入／卖出价 |
| 自动识别网页 / JSON | 识别下述 JSON，或中行式静态 HTML 表格；HTML 必须明确标注每 100 外币折算人民币的单位，日期按北京时间解释 |
| 自定义 JSON 数据 | UTF-8 JSON；`baseCurrency` 固定为 `CNY`、`unit` 固定为 `100`；`rates` 最多 128 种，币种名称不重复，至少提供一种正数报价，发布时间必须带时区 |

三家银行均按每 100 外币对应人民币显示，发布时间按北京时间解释。工行和招行未提供的折算价显示为空缺，不能推算成官方中间价。更换预设后先保存设置，再获取新银行数据；预设网址须保持对应官网，自定义网站应选自动识别或 JSON 格式。

自定义 JSON 示例（报价可以使用十进制字符串，避免数据提供方浮点舍入）：

```json
{"baseCurrency":"CNY","unit":100,"rates":[{"currencyName":"美元","buyingRate":"710.25","sellingRate":"713.10","middleRate":"711.00","publishTime":"2026-10-17T09:00:00+08:00"}]}
```

`cashBuyingRate`、`cashSellingRate` 和其他报价列可缺省，界面显示空缺而不补零。自定义地址须为公开 HTTPS，可带普通查询参数，不能包含账号、密钥、内网目标或片段；每次重定向重新校验地址，读取总预算 30 秒、响应上限 5 MiB。自动识别不是任意网站采集器：不执行 JavaScript、不登录、不绕过验证码，也不猜测币种、汇率方向或单位；不符合格式时明确报错，需要来源提供约定格式或另行开发适配器。

页面明确显示“每 100 外币折算人民币（CNY）”、最近获取和来源发布时间；这些是参考报价，不自动改写已保存或正在编辑的单据汇率。中行牌价实际结购汇以银行交易报价为准，未经中国银行许可不得以商业目的转载其汇率表；使用其他来源同样须遵守其规则。

## 保存和敏感字段

普通分类由顶部“保存全部修改”提交草稿；备份分类使用“保存灾备设置”，同时保存计划、所选存储和凭据。标题区和导航标记未保存修改；灾备保存只合并已确认的共享连接字段及版本，不覆盖其他分类草稿。重新加载、离开灾备页、保存失败和多人冲突均保留草稿保护。

“恢复本分类默认”只更新当前分类中有正式默认值的设置，确认后先写入草稿，不会改变其他分类或切换数据库类型。保存和校验继续使用现有 `Revision` 并发保护。

数据库连接、邮件和 AI 的密码开关保持原语义：填写新值才替换，空值保留。灾备页提供逐项凭据修改开关，未勾选保留，勾选后留空清除所选存储凭据；备份包密码留空保留原值。凭据不回传，不使用浏览器持久存储。

## 运行、备份和日志

- 健康接口的 `databaseProviderKey` 返回 `sqlite` 或 `postgresql`。界面使用同一标识展示数据库设置和团队备份入口，状态读取失败时显示错误及重试入口。
- 软件更新地址仅桌面端显示；默认导出目录作为共享配置，正式输出仍以用户明确选择的位置为准，不自动建立新的输出目录。
- “日常灾备”默认关闭；可立即执行完整加密快照，或按业务时区每天／每周运行。保留策略在新包及所选副本成功后执行，只处理本仓库登记文件，至少保留一份。旧自动备份字段不自动开启新计划。
- “异机副本”可切换 WebDAV／NAS 和 S3，测试已保存配置的写入、回读及删除。默认回读 SHA-256 校验；副本失败保留本地包及旧备份，显示部分完成。历史 SQLite WebDAV 工具默认折叠，仅打开时访问远端。
- 数据库恢复确认文本为 `RESTORE DATABASE`，完整迁移创建/恢复为 `MIGRATE`。暂存后须停应用并执行独立恢复维护命令，普通重启不会恢复；分步操作见[服务器恢复指南](./服务器备份迁移与恢复指南.md)。
- 最近完整备份可直接下载或用于服务端恢复，避免浏览器往返搬运。恢复页另提供外部包和数据库快照入口；路径、角色等高级信息默认折叠。后台任务完成后刷新状态，暂存成功显示维护步骤；Docker／网页实际恢复仍由部署管理员执行独立维护命令。
- “维护工具 → 日志管理”集中维护日志和审计保留规则。清理旧日志前需先保存草稿，清理操作不隐式保存其他修改；审计记录的查询及清理仍在“系统管理 → 审计日志”中维护。

配置保存在当前业务数据库，敏感值由受管主密钥保护，读取时返回脱敏状态。数据库由启动组合根决定，界面配置不切换当前服务连接；SQLite 文件名固定为 exportdoc-native.db。当前只接受全新 schema 9，旧试验库须保留需要的原件后显式新建目录/数据库，不自动升级或覆盖。分类和分组选项通过受控地址参数定位，未保存草稿只在页面内存中维护。
