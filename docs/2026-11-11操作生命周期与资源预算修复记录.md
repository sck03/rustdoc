# 2026-11-11 操作生命周期、资源预算与 CI 修复

从 `45ccb693` 继续项目审查及上次中断的实施。沿用 React／Tauri／Rust 分层、schema 17 和单一原生契约，不增加旧版本兼容链。

## 实现

- 发票删除、反审核、状态变更和另一类型复制使用同一个类型化命令入口，复用 `useScopedMutation` 的串行执行、取消和刷新反馈。确认弹窗通过 `useScopedConfirmation` 绑定页面与客户端；切换记录或卸载后，迟到确认不能启动旧请求。保存继续保留续编、版本推进和 HS 反馈；关联列表刷新从保存等待中分离。
- 装柜分析复用 `useTransientPreview`，只接受当前请求的结果；设置中的灾备命令及 HS 维护确认统一使用现有作用域机制，不在 TanStack MutationCache 中额外保留大型输入、结果或备份密码。共享异步入口拒绝卸载后的新调用。
- HTTP JSON 接收与解析分开准入：每个服务实例有 64 MiB 的输入容量预算和 4 个解析名额，解析名额在完整接收后取得；无正文契约不读取正文。预算按端点的最大输入预留，随解析值保留到业务工作线程结束。接收空闲 10 秒超时；该预算约束输入，并不等于 JSON 对象或进程 RSS 的硬上限。
- 图片处理通过原生契约声明资源名额，JSON/Base64 印章、唛头及二进制上传进入同一处理通道。OpenAPI、运行契约和生成器同步投影；冻结契约回归在端点与正文演进完成后再核对该元数据，保留认证、权限、错误及容量比较。
- 图片预览／下载先取有界、已授权的字节快照，再释放数据库连接并校验摘要及解码；报表事务内读取继续保留原快照边界。OA 待办在一次查询内复用审批资格，并减少重复范围／办理检查；仍有跨来源应用层扫描，不宣称全部 SQL 下推。截止时间按实际时间点取最早值，排序键统一为固定纳秒精度 UTC，修复小数秒及不同时区偏移的字符串排序问题。
- 请求正文回归拆到专用测试子模块，发票控制动作独立于保存／图片上传；SQLite 注册函数与取消钩子统一在连接初始化阶段设置，校验、备份与恢复复用这一边界。
- 报表预览统一使用 `useTransientPreview`，响应与页码来自同一份结果；页面及编辑动作只接收生成、清除接口，不再分别维护 HTML 响应和分页状态。模板重新加载独立为用例 hook，只有当前模板／客户端的请求才能更新草稿和缓存；迟到确认不能启动旧操作。导出默认设置的保存与重新加载使用同一个类型化命令通道，后台刷新失败保留新草稿，保存不等待刷新。
- 根据本会话截图反馈，删除与页头调用同一生成逻辑的“样例预览／真实数据预览”按钮，统一从页头“预览”生成；预览方式、数据来源和样例档案在宽屏同行显示，窄屏按空间排列。同步更新真实 HTTP、桌面和私人模板回归的操作入口。
- AI 审查实例自行持有并发名额，用例只接收存储、凭据保护器和受管缓存路径，不再依赖整个 `NativeService`。现有实例隔离、取消和失败释放回归继续约束该边界；这不代表其它领域已全部从服务组合根拆出。

## GitHub 故障与安全依赖

读取 `45ccb693` 的 GitHub Actions 原始失败日志后分别定位：

1. `Rust native delivery validation` 的 Windows Storage 测试在清理时遇到 OS 32 文件占用。测试目录清理仅对 Windows 共享／锁冲突重试，预算由 2 秒调整为 10 秒；新增持续超过 2 秒后释放的回归，持续占用仍报错。
2. Chromium 报表预览夹具缺少当时 hook 必需的 `onReset`，且每次 render 创建新客户端。最终由预览 hook 直接持有结果并处理失效，删除外部 reset 回调；夹具改为观察真实状态并使用稳定客户端。设计器测试明确等待懒加载画布可操作，在失败输出中保留页面异常；没有放宽按钮断言或延长 UI 超时。
3. RustSec `RUSTSEC-2026-0459` 指出原 `libsqlite3-sys 0.38.2` 存在 SQLite 漏洞。仅升级 `rusqlite 0.40.2 → 0.41.1`、`libsqlite3-sys 0.38.2 → 0.39.1`，使用 bundled SQLite。两个 Rust 包继续为 MIT，SQLite 为 Public Domain；无商业授权变化，notices 与库存同步生成。新版可变取消钩子要求由共用连接初始化适配，不添加兼容分支。

SQLite 安全升级作为独立提交审计；其它依赖版本不变。Cargo 同时将原有 `cssparser-macros 0.7.1` 的解析依赖选择为锁图已包含的 `syn 3.0.9`，没有新增或升级 syn 包。当前审计结果 0 项漏洞；已有未维护提示仍单独保留，未扩大忽略列表。
