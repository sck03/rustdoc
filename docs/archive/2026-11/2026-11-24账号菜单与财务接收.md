# 2026-11-24 账号菜单与财务接收

## 实现范围

- 顶栏账号按钮靠右，按现有空间、字体、颜色、圆角和层级令牌分配宽度；共享菜单支持键盘、Escape、点击外部关闭及焦点恢复，680px 窄屏采用触控尺寸。
- 个人密码弹窗复用 Dialog、Field、Button；全局会话 hook 负责未保存确认、并发操作边界及退出广播，输入只保存在弹窗会话内。
- 原生契约新增已认证、无需业务权限／许可证的本人密码接口，保持桌面令牌边界及 4 KiB 正文上限。Engine 验证原密码、复用限流和哈希，在事务内校验账号版本、更新凭据及审计，撤销该账号会话。Storage 无新增 SQL 或 schema。
- 财务默认报销查看由本人调整为公司，财务接收保持公司，自助动作限本人，审批另行授权。自动办理候选排除维护账号，新建默认节点关闭维护接管；明确维护接管保留现有受控配置，旧发布版本不自动改写。
- 发布任职校验错误补充节点、部门。截图中的 0003 使用“部门审批人员＋财务人员”已发布方案，当前报销查看为部门；现有绑定须明确发布、应用公司查看的新版本。
- 删除独立退出按钮及其失效样式；认证会话测试移入独立测试目录。新增契约差异由独立冻结夹具逐项验证，其余接口和权限继续比较。
- 通知根据当前任务投影“是否仍需审批”和申请状态，保留历史事件、通知时间和已读事实。真实“部门审批＋财务”组合复现通知列表／未读数量 503；底层为 SQLite 重复展开流程任职查询触发复杂度限制。计数、分页复用一次可见编号筛选，审批身份分支共用任职来源条件，保持签署历史、委托、办理职责和单位隔离。
- 桌面窗口允许本应用来源的 Blob 导航；CSP 的 frame-src 接入预览。独立宿主下载模块校验本应用／受控下载地址并提供原生保存对话框，报表仍复用 Rust 排版，不使用 DOM 截图或第二套 PDF 生成实现。
