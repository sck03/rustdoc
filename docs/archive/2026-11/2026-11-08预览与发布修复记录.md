# 2026-11-08 预览与发布修复记录

基线：`2291529a`。本批修复审查确认的五项问题及两项资源边界，数据库维持 schema 14，没有依赖升级。

## 实现

- 发票与单据包使用共用短期预览 hook；源草稿、目录、选择、权限变化立即隐藏旧结果并取消请求，迟到成功/失败都不发布。打印动作也检查当前有效预览。移除两处 HTML mutation 缓存，释放历史大型响应。
- 模板目录刷新按稳定路径保留已选状态和印章选项，只初始化新增项并移除不存在项。
- Rust 每次 HTML 转换为页面 CSS/ID 和 SVG 内部引用分配文档/页前缀；不复制排版或在前端匹配特殊模板。
- 桌面完整灾备使用 `StartRecoveryArchiveSaveToPathJob`，源文件按大小和 SHA-256 校验，64 KiB 分块复制，HTTP 仍验证桌面令牌和管理员权限。网页原下载票据保持，不将桌面令牌放入 URL。
- 文件任务在事务外暂存输出和旧文件快照，数据库事务只复核权限、目标和发布状态；失败/取消清理暂存，提交不确定时保留恢复清单。单文件与目录共用 schema 2 发布清单，旧清单明确拒绝；大备份保存不读入 Vec 或浏览器 Blob。为限制已有目标的补偿成本，超过 64 MiB 的已存在目标须另选文件名。
- SVG、PDF 页图和报表输出统一串行转换，等待五秒返回 429，并检查操作取消。HTML 单份及组合累计 32 MiB；HTTP 每份预览预留 64 MiB、总计 128 MiB，容量不足返回 429，发送/断开后回收。此预算控制响应缓冲，不能等同于整个进程 RSS 上限。
- 维护读写锁共用取消感知的获取逻辑，最长等待 30 秒，较短请求期限优先，保留锁损坏错误。
