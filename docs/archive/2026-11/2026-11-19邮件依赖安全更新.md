# 2026-11-19 邮件依赖安全更新

GitHub 定时安全审计运行 [44284374549](https://github.com/sck03/rustdoc/actions/runs/44284374549) 在 `lettre 0.11.23` 上报告六条安全公告。本次独立升级到精确固定的 `0.11.24`，关联 `email-encoding` 从 `0.4.2` 更新到 `0.4.3`。其余依赖版本和锁图边保持原样。

`lettre` 为 MIT，`email-encoding` 为 MIT OR Apache-2.0，继续允许既有商业交付；没有新服务、格式锁定或运行工具。生成的依赖清单与 notices 同步更新。

本地使用仓库 `CARGO_HOME` 和受管 RustSec 数据库执行与 CI 相同的 `--deny unsound --deny yanked` 审计，现行锁图报告零项未豁免漏洞。原有 GLib `RUSTSEC-2024-0429` 例外及八项停止维护警告保留，并未宣称上游问题已修复。发布依赖治理核对 840 个组件，`unresolved=0`、`disallowed=0`，`--release --verify-repository` 通过。
