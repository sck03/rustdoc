# 2026-11-10 导出一致性、资源占用与共享控件

本批针对项目复核的六项问题及五处截图问题实施。继续使用全新 schema 17、755 个 API 操作和 702 个运行 schema；不新增依赖、旧库迁移或兼容分支。

## 实现边界

| 问题 | 当前行为与职责 |
| --- | --- |
| 单一窗口导出可能绕过未保存编辑、取消或版本检查 | COO/ACD 提交包必须传正整数 `expectedDraftRevision`。Engine 拒绝未保存、版本过期或来源已改变的草稿；不隐式保存初稿。页面复用单据工作区的互斥操作与取消信号，保存期间不能导出，关闭/切换后的迟到响应不能触发下载。文件准备后的事务重验继续保留。 |
| HS 文件操作长期保留 File/Blob | 知识包导入/导出和本地文件预览复用 `useScopedMutation`，不进入 TanStack mutation 缓存；身份、权限或页面作用域变化取消请求，成功后重置原生文件输入。 |
| 自定义 OA 明细引用逐字段查询 | 独立 `custom_form_references` 模块先收集并去重人员/部门引用，Storage 共用每批最多 200 个键的参数化查询；同一授权快照内校验任职、公司及启用状态，再生成冻结显示值。数据库查询不进入 Domain 或 UI。 |
| 已删除 OA 草稿扩大每次设置读取 | 删除时事务内保留最小编号占用记录并按版本删除活动草稿。设置响应只读取活动草稿及其版本；删除后的编号不可重新创建，防止迟到写入复活。占用记录仍随删除数量增长，但不进入设置列表扫描和响应。损坏活动草稿明确报错。 |
| 空白可选数字触发审批条件错误 | 表单校验和审批条件共享 `nonblank`；空串及 Unicode 空白视为未填写，非空值继续按精确数值规则校验。 |
| 待办翻页重复计算全部来源汇总 | `GetWorklist` 增加 `includeSummary`，默认 `true`。`false` 省略 `totalCount`、`totalPages` 和来源 `count`，按来源过滤及游标位置跳过无关查询，已有足够结果后跳过后续来源。相关来源仍按当前业务权限排序筛选，不增加跨请求权限缓存。React 分开获取当前页和一分钟汇总，仅首页轮询，错误或后台状态停止周期请求。 |

## 统一控件

- `TextAreaSetting` 复用 `TextAreaField`，单据邮件正文与 AI 系统提示词默认七行，支持纵向调整；短文本字段保留原有行数。
- 待办页使用公共 `Pagination` 的游标模式，复用横向“每页 / 数量 / 条”布局，保留首页、上一页、下一页，移除游标无法支持的任意跳页。
- 可见文件选择统一使用 `FileInput`，固定显示中文“选择文件 / 未选择文件”，统一留白、高度、边框及禁用状态。透明原生输入保留系统选择器、键盘和标签语义；组件只保存文件名，不缓存 File。已有中文触发按钮的隐藏输入继续复用原有流程。
- 操作档案选择与档案名称使用相同 `FieldShell`，统一标签与控件对齐。
- 网页及真实 WebView2 包复用同一布局验收函数，避免两套控件断言漂移。
- 待办顶栏在滚动后的整页截图中落在页面中间，源于截图记录了 sticky 元素相对整页的位置。改用实际视口截图，并分别检查页面顶部和底部滚动后的顶栏坐标，避免把长截图伪影误判为页面布局。
