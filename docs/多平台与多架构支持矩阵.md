# 多平台与多架构支持矩阵

> 2026-10-14 核对交付目标。这里区分目标支持与实际验收；旧 C# / Slint / egui 结果不作为当前 Rust 桌面证据。

| 产品/目标 | 数据库及显示组件 | 验收要求 |
| --- | --- | --- |
| Windows x64 桌面 | SQLite + WebView2 | 当前宿主优先联调；GNU 构建不替代 MSVC 发布 |
| Windows ARM64 桌面 | SQLite + WebView2 | 对应 runner 编译及设备实跑 |
| Linux x64/ARM64 桌面 | SQLite + WebKitGTK 4.1 | GTK/WebKit 依赖、窗口系统、文件对话框及打印 |
| macOS ARM64 桌面 | SQLite + WKWebView | AppKit、Retina、中文输入、.app 与打印 |
| 网页：Windows x64、Linux x64/ARM64、macOS ARM64 | PostgreSQL 18 + 同一 React | 独立服务包、数据库角色、认证、上传下载、反向代理与恢复；Windows 网页未提供 ARM64 客户端包 |
| Docker：Linux amd64/arm64 | PostgreSQL 18 + 同一 React | 两容器生命周期、内部网络、凭据/卷隔离、备份恢复 |
| 中等/窄屏浏览器 | 同一 React 与接口权限 | 响应式、键盘/触控、溢出与草稿保护 |

Intel macOS 不属于当前交付目标。正式桌面及三端 Actions 的 All 为 Document、Sales，默认 Document；本地脚本另支持显式 `-Edition Full` 的 SQLite 测试便携包，用于完整界面/流程验证。网页/容器为 Full 多用户版。Full 测试包不进入正式安装器和发布矩阵。各 OS/架构的编译、运行及签名升级分别验收，本机 Windows 测试不能代替其它 runner 或 PostgreSQL 多用户部署。

## 证据边界

OCR 由桌面本机或网页/Docker 的 Rust 服务端执行；浏览器和移动端上传图片，不运行本机 ONNX。Windows ARM64 CRT 缺口已在 2026-10-15 补齐，其他架构仍按真实 runner/设备证据记录；版本、资源及 RapidOCR 比较见 [OCR 评估](./OCR跨平台与RapidOCR评估.md)。Sales 和显式 WithoutOcr 包不提供识别。

- Windows 本机检查只证明本机对应源码及运行环境；其它系统/架构逐一记录。
- 普通质量门禁运行 Chromium 主路径；Firefox/WebKit 仅由 browser-compatibility.yml 手工触发。
- PostgreSQL 集成测试必须启动隔离的真实 PostgreSQL 18；标记 ignored 的测试不算通过。
- Docker 生命周期、Linux/macOS/ARM64 真机、实体打印偏移、正式升级各自验收。
- 2026-10-14 已在 GitHub Linux amd64 runner 完成真实镜像构建、直接安装、数据库恢复及重启保留数据；该结果不覆盖 ARM64 镜像或 Linux 桌面，运行链接与具体范围见进度文档。
- Tauri/WebView、SQLite 与共用 Rust 服务进入桌面图；网页服务不带 Tauri，桌面不带 PostgreSQL 服务端适配器。
- 不执行 Authenticode、Developer ID 或 Apple 公证；updater 包签名与公钥校验继续保留。
