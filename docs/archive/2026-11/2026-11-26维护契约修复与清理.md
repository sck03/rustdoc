## 行为与模块边界

- 系统设置的文本日志清理只处理 DataRoot/Logs 内的 .log、轮换 .log.N 和 .jsonl 文件，读取已保存的天数／份数设置；取消、目录读取和文件删除错误均传播，重复清理幂等。它不删除数据库审计记录，也不触碰目录中的其他文件。审计记录继续通过现有独立审计页面筛选、预览并确认删除，删除了许可证模块内重复的五万条扫描与审计删除链路。
- 支持包和文本日志迁入 Engine diagnostics 的独立子模块；许可证模块只管理授权。支持包保持五份脱敏 JSON 摘要，移除未实现的“包含数据库备份／样张”选项和请求 DTO。三个维护端点从原生元数据明确声明 system.settings/manage 管理员权限。
- 支持包的审计统计通过 Storage 只读快照查询，返回精确 totalEvents 与 oldestEvent；不再加载完整审计事件、截断五万条或持有写协调锁。时间排序沿用带时区和纳秒精度的存储函数，损坏时间返回依赖错误。取消逐日及动作分组的额外扫描，不传输业务审计正文。
- 默认导出目录由专用桌面选择命令转换为 DataRoot 内的相对路径，保存校验与桌面解析共用 Engine paths/managed；拒绝越界、跳转段和链接。空默认值从数据根打开目录选择器，保存对话框按显式注入的 DataRoot 解析相对目录。普通一次性导出仍由用户选择实际目标。
- 数据库类型与 SQLite 文件名只读，恢复默认值不改变运行身份；默认值统一为 exportdoc-native.db。移除 14 个失效配置：旧 PostgreSQL 自动备份五项、连接参数六项、backupRetentionDays、auditLogRetentionDays 和 logFileSizeLimitMB。有效备份计划仍使用独立 BackupPlan。SystemSettings 拒绝未声明字段，读取只投影现行字段。
- 桌面错误日志在每次打开追加句柄前检查 20 MiB 阈值，最多保留三个轮换文件；不再提供无效的可修改大小选项。轮换失败传播真实 I/O 错误，保留活动日志。HTTP 请求日志继续采用原有约 8 MiB 的独立有界轮换。
- 附件在线预览限定为 16 MiB 以内的 PDF／受支持图片，读取前检查版本元数据；大附件继续使用现有下载票据／桌面保存链路。切换预览前释放旧 Blob，取消后不发布结果。此项是明确的内存预算约束，没有把静态分析宣称为性能实测。
- 前端沿用共享字段、详情网格、提示、确认框及现有设计令牌；恢复默认值的分类与运行模式筛选集中在同一模型中，网页不显示无效的桌面默认值恢复操作。
