## 文档维护

当前事实只说明现行行为；操作手册给出步骤和失败处理；带日期档案保存当批证据，不能证明当前源码或其它平台已通过。旧方案、旧 schema 和已完成的实施流水放在 archive，新增记录不再重复堆入本总览。

修改能力时同步正式契约和相关专题；纯文档改动运行本地链接检查与 git diff --check。可复用资源、冻结测试契约、客户数据与用户备份不按文档或截图清理。未运行的平台/设备明确写待验。
