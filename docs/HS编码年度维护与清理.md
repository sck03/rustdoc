# HS 编码年度维护与清理

HS 编码目录、年度导入和失效清理使用同一业务数据库。当前实现边界以[架构事实](./当前架构事实.md)为准，实际验证见[进度](./程序改进重构进度文档.md)。

## 未更新年度资料时

**没有导入新年度 HS 资料，不会把原有编码清理掉。** 跨年后，旧年度有效资料显示“待年度复核”，继续保留，可查阅作为参考；只有经过验证且适用年度等于业务年度的编码可以作为当前有效税则。

| 编码状态 | 保留规则 |
| --- | --- |
| 有效／待年度复核 | 不因时间经过而清理 |
| 仅供参考 | 不因时间经过而清理 |
| 疑似作废 | 核对官方资料后，人工确认作废；不自动删除 |
| 已作废 | 最后更新满 12 个日历月后，可手动预检并确认清理 |

保留期按带时区的最后更新时间计算，增加 12 个日历月；不是按年份切换，也不是把旧年度资料统一删除。确认作废会记录原因、确认时间和新的最后更新时间。后续再次修改该编码，会从新的最后更新时间重新计时；重复确认同一已作废版本不会重新计时。日期不明的记录保留。

## 年度维护步骤

1. 打开 HS 知识库的“年度税则智能导入”，选择资料来源、适用年份和文件。零散资料使用增量导入；确认文件完整时，才选择完整年度库。
2. 在预检中按新增、更新、不变、疑似作废、冲突和无效类别筛选，逐页核对后确认导入。完整年度文件存在冲突或无效行时，先修正文件再重新预检。
3. 完整年度文件缺失的原有效编码只标记为“疑似作废”。核对官方公告和替代编码，使用详情中的“确认作废”，或在目录多选后批量确认；填写原因后提交。
4. 大量缺失编码使用同一工具区的“疑似作废批量核对”。一次读取最多 5000 条，可跨页选择、选择本批全部并逐条排除；确认只处理选中的记录。尚未核实及超出本批的编码继续保留。
5. 已确认作废且最后更新满 12 个日历月后，打开“失效编码清理”，先预检，逐页查看本批，再确认清理。每批最多 5000 条，预检 30 分钟内有效，只能提交一次。

详情“数据来源与有效性”显示已确认作废的原因和时间。状态通过上述专用操作及年度导入维护；手工新建只能作为参考，不能把参考编码自行标成当前有效。

## 并发与历史资料

单条／批量确认作废、普通删除均使用读取或选择时的版本。另一人更新了其中任一记录，整批操作拒绝并回滚；重新读取、核对后再提交。清理同样复核预检版本及保留期。

失效清理和普通目录删除只删除对应编码目录记录。历史单据、商品、申报实例、归类经验和替代关系继续保留，不自动改写为新编码。管理员“清空整库”是独立维护操作，需要输入 `CLEAR`，会删除全部目录编码。

当前较旧年度不能覆盖较新资料；未来年度须待生效后导入。目录按编码维护，没有完整的多年度税则并存查询。HS 税则及上述维护不代替正式申报时对适用税则的核对。
