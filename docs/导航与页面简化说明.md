# 导航与页面简化说明

> 2026-09-09。产品能力和最新验收结果以《当前架构事实》为准。

## 全功能版包含行政功能

单机 Full 使用与 Administration 相同的行政登记模式，包括人员档案、会议室预约、钥匙交接、物品领用、库存和归还。先建立人员档案，再选择人员登记预约或领用；单机不需要员工登录和双人审批。未结清钥匙或借用物品仍会阻止离职。个人待办按权限汇总行政交接和人事到期事项。

Full 的默认首页仍为单证概览，独立行政版默认进入人员档案。Document、Sales 单机版保持各自产品范围。团队版继续使用 PostgreSQL 申请与独立审批流程。

## 按任务查找功能

主导航由七组收敛为六组，业务入口全部保留。采用常见业务软件的固定分组、当前分组展开、页内操作和低频动作折叠布局。

| 分组 | 内容 |
| --- | --- |
| 工作台 | 我的待办、单证概览、销售概览、文件任务 |
| 客户与供应链 | 客户跟进、商机与报价、供应商管理、邮件模板 |
| 单证与申报 | 发票管理、统计查询、付款报销、业务资料、单一窗口、申报词典、HS 编码知识 |
| 公司行政 | 人员档案、会议室预约、物品领用 |
| 资料与工具 | 基础资料、报表模板管理、Excel 工具、文字识别、装柜模拟、今日汇率、邮件发送 |
| 系统管理 | 系统设置、账号与权限、审计日志、软件更新、授权注册、关于系统 |

实际菜单只显示当前产品、运行模式、可用模块和账号权限允许的功能。顶部“查找功能”可以直接搜索业务名称，也支持“任务中心”“主数据维护”“智能 OCR”等原名称。搜索不会暴露未授权入口，原有业务网址不变。

默认只展开当前分组，切换分组收起上一组。精简导航栏显示六类分组及文字，点击即可展开；手机继续使用可关闭的抽屉，支持搜索、Escape、键盘焦点循环和返回页面。

## 页面操作简化

- **批量报表：** 在“文件任务 → 批量报表 ZIP”中按发票号或客户搜索，逐张加入清单。清单显示发票号和客户，可移除误选项；重复选取不会重复输出，无需填写数据库 ID。模板和带章选项沿用原输出链路。
- **物品领用：** 卡片优先展示登记／申请和补充库存。库存流水、盘点、编辑通过“更多操作”展开，分别保留原权限校验。领用、发放、归还记录继续在页内标签处理。
- **名称与定位：** 菜单名称和普通页面标题共用一份定义。编辑页保留“新建发票”“报表设计”等操作标题，所属业务分组一致；HS 税则目录和知识页面只激活同一导航入口。

## 保留的业务边界

以下页面看起来相近，但服务于不同任务，继续分开：

| 页面 | 分工 |
| --- | --- |
| 我的待办 / 文件任务 | 前者处理需要人工办理的业务事项；后者查看后台处理、下载结果、取消和重试 |
| 发票管理 / 统计查询 | 前者创建和维护单据；后者按日期、客户和商品统计、检索、导出明细 |
| 客户跟进 / 基础资料中的客户 | 前者处理销售联系人、跟进和商机；后者维护制单使用的往来资料 |
| 报表模板管理 / 报表设计 | 前者选择默认模板、维护文件及模板包；后者编辑所选模板版式 |

本次重构集中在入口组织、默认信息量和操作方式。复用现有 React 组件、查询、领域服务和授权，不增加 UI 框架、第二份 API 契约、客户端持久化或数据库兼容层。
