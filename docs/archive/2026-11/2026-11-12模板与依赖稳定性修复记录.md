## 空间清理与交付

先核对路径、Git/链接边界、运行进程及包内清单，再清理 258 项 Cargo 测试可执行文件/元数据，以及 36 项旧测试程序文件和隔离 UI/数据库/截图日志目录。文件逻辑大小不作为磁盘释放量：两次清理实测可用空间合计增加 9,739,608,064 字节，约 9.07 GiB。

保留新的 Full 测试包、Cargo 编译库和下载缓存、浏览器/原生工具缓存、私有备份，以及旧测试包内来源不能认定为废弃的 `App_Data`。旧程序只删除 SHA-256 与打包清单一致的受管文件。没有删除正式业务库或用户备份，也未改动数据库 schema。依赖升级独立提交，其他改动集中提交；GitHub 门禁结果以本批主分支提交对应的 Actions 为准。

宽屏跟进再次按文件哈希、进程占用及链接/Git 边界核对，清理 12 个已完成的 UI/视觉/规模测试输出目录和 2 个本次 Excel 单元测试产物，磁盘可用空间两次实测合计增加 108,343,296 字节（约 103.3 MiB）。当前 `target` 的盘点逻辑大小约 87 GiB，主要是可复用编译产物；按现有缓存保留规则未整体删除。新 Full 包、当前验收证据、业务库及来源不明的数据继续保留。

GitHub 首次运行暴露发布脚本工作流未安装前端构建依赖，导致 SPDX 回归找不到解析库。补齐工作流的 locked npm 安装、缓存及清单变更触发路径。仓库 Dependabot alerts/security updates 已通过 API 启用并确认 `enabled=true`、`paused=false`。

Linux Chromium 回归另暴露测试时序问题：发出关闭/权限更新后，尚未等 React 提交就返回迟到的原生对话框结果。测试改为等待页面关闭或字段禁用的真实状态，再验证旧结果不能触发导出或回填；保留原有取消断言，不延长固定等待。本地 47 场景复验通过。依赖安全与 SBOM 的 [GitHub 运行 43159703866](https://github.com/sck03/rustdoc/actions/runs/43159703866) 已通过。

## 保留的边界

GLib 的 RUSTSEC-2024-0429 已在 0.20 起修复，但当前 GTK3 依赖链使用的 0.18.5 没有兼容补丁，现有例外只在锁定 Tauri 2.12.5 且消费者未引用受影响符号时成立；源码扫描通过不表示缺陷消失。另有 proc-macro-error、rustybuzz、ttf-parser、zbus_names、zvariant、zvariant_derive 的停止维护提示，须通过其上游依赖链继续评估替换。不能以此把现有平台栈强行升级到 API 不兼容版本。

当前改动不涉及 schema、SQL 或 HTTP 契约。PostgreSQL、Linux/macOS/ARM64、超大备份与实际系统输入法候选窗的独立验收不由本次 Windows 测试替代。
