## 2026-11-13 文件存储、容量和部署文档

永久附件、图片和正式 PDF 接入统一文件存储，数据库采用全新 schema 18；补齐引用/配额、游标目录、有界上传、Range 下载、迁移、备份对象校验及受控回收。前端复用共享设置和任务组件，本地脚本、GitHub 工作流、部署与卸载说明以及两份 OA PDF 手册同步更新。实际门禁、清理量和未验收边界见[本批记录](./archive/2026-11/2026-11-13文件存储重构与清理记录.md)。

收尾定向清理旧编译产物、过期测试包和隔离数据后，E 盘可用空间实测增加 **29.28 GiB**；432 个受保护文件及当前 Full 包 41 个文件的 SHA-256 全部一致。当前包、最新验收证据和可复用依赖/编译缓存保留。

## 2026-11-12 OA、资源生命周期、文档与清理

已完成部门多选、草稿引用名称配对、共享轮询、无缓存维护/装柜命令、后台目录刷新、可取消通知锁、内置办理节点类型化、每月版本更新及每周完整依赖治理。最终验证通过 Rust 工作区、前端、PostgreSQL 18 及 Windows Full 测试包；[本批验收记录](./archive/2026-11/2026-11-12OA资源与文档收尾记录.md)列出范围与环境边界。
