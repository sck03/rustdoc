# OA 系统用户手册

业务协同平台 · Full

发起申请 / 审批与办理 / 进度与资料

版本日期：2026-11-12　适用程序：0.1.2

适用对象：普通员工、获授权的审批人及实际办理人。

本手册使用匿名业务示例。系统根据当前账号、单位身份和流程分派显示功能；没有看到某个入口时，先核对身份和管理员授权。

Full 网页版用于团队协作；Full SQLite 为独立测试版。Document、Sales 桌面版的制单/销售功能不等于完整 OA 团队功能。

---

## 01 登录、身份与入口

1. 打开管理员提供的网址，使用自己的账号登录。不要借用同事或维护管理员账号。
2. 核对姓名、单位、业务日期及页面顶部的当前身份。
3. 如果有多个任职或单位身份，先选择本次业务对应的身份。相同部门的不同岗位也可能有不同上级和权限。
4. 打开“工作台 → 申请与审批”。常用入口为“审批与进度”“待我办理”“发起申请”。
5. 在发起申请中按名称或分类查找请假、加班、报销、出差、采购、通用事项或公司新增事项；会议室和物品从资源入口选择。

切换身份或离开编辑页面前，先保存草稿或明确放弃修改。切换后页面会按新身份重新查询；旧身份的权限不会继续生效。

如果账号没有关联有效人员/任职，可能无法发起申请。请向管理员提供自己的登录名、单位和工号，由管理员核对关联；仅修改显示姓名不能解决问题。

## 02 新建申请与保存草稿

1. 点击所需事项的“发起申请”，核对申请人及申请任职。
2. 填写申请标题和说明；标题说明目的，正文写清时间、用途及需要审批的事实。
3. 按事项填写日期、类别、币种、金额、明细或其他专用字段。
4. 人员/部门字段点击“选择人员”或“选择部门”，搜索后选择正确对象，不手写编号。
5. 明细表点击“添加明细行”，填写各列；不需要的行用“移除此行”删除。
6. 按需选择附件及用途，点击“保存草稿”。
7. 保存后进入详情，检查资料和附件，再决定是否提交。

草稿可以暂时不完整。保存草稿不是提交审批，审批人通常还没有收到需要签署的任务。保存失败时保留输入并阅读提示；如果资料已保存但部分附件失败，按页面提示继续处理剩余文件。

重新打开已保存草稿时，系统保留人员/部门引用名称。发现选错对象应重新选择；删除或调整明细行后再次核对对应关系。

## 03 附件、提交与进度

附件用途可选择报销单、发票/其他凭证或补充资料。上传前确认文件内容和所属申请；不能仅靠文件名判断资料正确。文件类型、大小、数量等以当前页面的实际提示为准。

1. 在申请详情检查标题、任职、时间/金额、明细和附件。
2. 如需修改，点击“编辑草稿”，修改后保存。
3. 查看可用的审批路径预览，确认没有缺少负责人或身份失效提示。
4. 点击“提交审批”，填写需要的说明并确认。
5. 提交成功后在“审批与进度”查看当前节点、责任人和历史意见。

| 显示状态或情形 | 下一步 |
| --- | --- |
| 草稿 | 编辑完善后提交，或按允许动作删除/取消 |
| 待审批 | 等待当前节点处理，可按规则催办或取消 |
| 退回修改 | 阅读原因，修改材料后重新提交 |
| 已批准 | 检查是否还需要财务/行政等后续办理 |
| 暂停或执行受阻 | 查看提示，联系流程管理员，不重复新建相同申请 |
| 已完成/已取消/已驳回/已终止 | 查看最终结果及历史；需要新业务时重新申请 |
| 已交接财务 | 财务已登记接收，不代表银行已经付款 |

## 04 示例：请假和报销

请假：选择请假事项 → 核对任职 → 填写日期/时段、类别和原因 → 保存草稿 → 核对天数与路径 → 提交 → 跟踪审批和人事办理。假期计算按公司工作日历，发现天数异常先向管理员核对日历和字段，不用修改说明冒充正确时长。

报销：选择报销事项 → 填写标题、说明及币种 → 逐行填写费用日期、内容、金额等字段 → 上传报销单和凭证 → 保存 → 提交。

报销提交前检查：币种是否一致；明细金额与凭证是否对应；是否重复报销；附件是否完整。审批人退回时按意见修改，重新提交会保留上一轮意见和原材料。

审批通过后，财务可能仍需核验和接收。详情中的接收记录是 OA 交接事实，实际付款按公司财务制度查询；不要将“已批准”或“已交接财务”作为付款凭证。

公司自定义事项也遵循“草稿 → 提交 → 审批 → 实际办理”的步骤，例如“样品寄送”可能需要客户、运费、收件部门和样品明细。字段与适用部门由管理员发布的规则决定。

## 05 退回、取消与再次提交

收到退回修改时，先阅读退回原因和节点记录，再编辑获准修改的材料。补齐后保存并重新提交；系统形成新提交轮次，保留旧签署和原件。

草稿和在途申请可执行哪些动作，由当前状态和发布规则共同决定。详情中没有“取消”或某项流程操作时，不能通过修改地址或借账号操作。

已提交申请的任职不能直接切换。如果本次业务属于另一个身份，应先按允许的流程处理原申请，再切换正确身份重新发起。

管理员更新表单后，旧草稿可能提示需重新发起。先保存必要资料，按新事项重新填写，检查新字段和附件要求；不要假设旧草稿已经自动满足新规则。

网络中断或点击后长时间无响应时，先回到详情或文件任务检查是否已经成功。版本冲突说明记录已被别人或其他操作更新；保留输入，读取最新状态后再决定。不要连续重复点击产生无法判断的业务结果。

## 06 审批人的操作

本节仅适用于获授权并被分配任务的人员。

1. 从“审批与进度 → 待我审批”进入任务，核对申请编号和当前节点。
2. 阅读本节点获准的材料、附件和历史意见。未来节点的材料权限不会提前开放。
3. 完成要求的核验项目，填写清楚的审批意见。
4. 选择批准、退回修改或驳回等当前可用动作，确认后查看最新结果。
5. 需要代理、交接或加减签时，使用当前规则允许的流程操作；没有相应入口则联系流程管理员。

会签节点可能仍等待其他人；本人点击批准不代表整份申请已经完成。申请人不能审批自己的申请，同一自然人也不能通过切换账号、任职或代理重复满足独立复核。

代理操作保留原责任人和实际签署人。不要替他人登录签署，也不要在意见中写“代某人同意”来替代正式代理或交接。

材料被隐藏时请按职责处理，不能通过历史链接或原件包绕过范围限制。确实无法判断的，按流程退回或联系管理员核对配置。

## 07 待我办理、会议室与物品

审批表示同意，办理记录现实执行。获批后在“待我办理”或对应业务的办理页进入分配给自己的节点。

1. 检查审批结果、材料及应完成的动作。
2. 实际完成寄送、采购验收、财务接收或其他职责。
3. 点击“办理此节点”，填写实际办理说明和要求的核验数据。
4. 保存办理结果，查看下一节点或完成状态。

会议室：选择资源和时段发起预约，按容量/冲突提示调整；批准后办理交接，结束后登记归还或结束使用。不要只在备注里写“已归还”而不完成对应动作。

物品：选择品项、数量和用途；审批通过后可能预留库存，随后由保管人实际发放。借用品按已发数量登记分次归还，耗用品通常没有归还步骤。库存不足或版本冲突时按提示刷新核对。

已经发生发放、交接等现实动作时，取消或终止审批不能抹去这些事实；使用实际归还/补偿操作，并由管理员处理异常。

## 08 通知、审批单与材料

在公告和通知入口查看与自己相关的消息。通知链接只负责定位业务，进入记录时仍检查当前权限。仅收到抄送并不表示能审批或查看全部材料。

在申请详情查看审批意见、办理历史及归档状态。可用时点击“下载审批单 PDF”，等待文件任务完成或浏览器下载。检查下载目录、文件名及 PDF 内容，不只看“下载已开始”。

PDF 和原件 ZIP 按当前身份裁剪材料。没有完整材料权限时，可能只能下载受限 PDF，不能取得全部原件。原件包和审批签署记录应按公司制度保存和分享。

长申请可能有多页，检查页码、明细续页和全部签署记录。发现缺页、乱码、金额或附件不一致时，向管理员提供申请编号、生成时间和具体页码，不将错误版本继续流转。

OA 审批单不等于电子印章认证，也不替代公司的实际付款凭证。不要把包含私密资料的截图、PDF 或原件上传到不相关的外部服务。

## 09 常见问题与求助信息

| 问题 | 自助检查与下一步 |
| --- | --- |
| 看不到申请事项 | 确认 Full、当前身份、适用部门；请管理员确认已发布并启用 |
| 没有有效申请人/任职 | 核对单位、工号、关联账号和任职期限 |
| 提示没有可用审批人 | 请管理员核对负责人、岗位、权限或规则；不要换名字绕过 |
| 按钮不可用 | 核对状态、当前节点、本人职责和是否仍在保存 |
| 表单提交失败 | 查看字段错误，展开出错分区；补必填、附件、日期/金额 |
| 文件上传失败 | 按具体提示检查格式、大小和网络；已保存部分不要重复建单 |
| 403/无权限 | 重新确认身份；确需业务授权时联系管理员 |
| 409/版本冲突 | 保留输入，读取最新状态后重新判断 |
| 429/繁忙 | 稍后重试一次，并先检查是否已有成功记录 |
| 503/504/网络问题 | 保留申请编号和时间；检查任务回执，联系管理员核对服务 |

求助时提供：操作时间、所在单位/身份、申请编号、执行步骤、完整错误文字；必要时提供遮盖无关私密信息的截图。不要提供密码、令牌、密钥或整份生产数据库。

每次离开前确认草稿是否保存。终态申请不再自动轮询；如管理员刚处理了异常，可重新打开详情或使用页面的刷新/重试入口核对。
