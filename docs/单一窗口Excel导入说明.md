# 单一窗口 Excel 导入说明

核对日期：2026-11-12。单一窗口“申报资料”下载独立的 single-window-coo-template.xlsx；发票目录“下载报关 Excel 模板”使用 invoice-import-template.xlsx。两份模板各有明确用途。

## 产地证模板

| 工作表 | 填写位置 | 用途 |
| --- | --- | --- |
| 基本资料 | B3:B22 | 客户发票号、日期、币种、价格条款、收发货人、运输与证书资料 |
| 商品明细 | 第 3 行表头，第 4 行开始 | 一行一种货物，以生产企业编号关联工厂 |
| 生产企业 | 第 3 行表头，第 4 行开始 | 一家工厂填写一次，编号唯一 |

浅黄色为填写区，不表示必填。保留三个工作表名称、表头和基本资料标签；不要合并商品行。模板预设 100 行填写区，最多支持 5000 行商品、1000 家生产企业。常规行高 18 磅，地址等多行字段 30 磅，明细仅冻结紧凑的前 3 行。

商品 A:K 共 11 列，依次为中文品名、英文品名、HS 编码、数量、英文单位、包装件数、包装单位、单价、发票金额、FOB 值、生产企业编号。款号、毛净重和原产地标准及其后专业列已移除；正式布局与导入映射同步更新，旧的 20 列模板请重新下载。

- 同一原产国可填写基本资料 B22；不同原产国由操作员导入后逐项修改。中国原产填 CHINA，不能根据出口国或工厂地址推定原产资格。
- 款号和重量不再向普通填表人采集；最终申报字段按证种与实际货物在程序中核对。
- 英文品名是商品名称，例如 COTTON SHIRTS；货物英文描述是证书票面描述，可包含包装和名称，例如 TWO (2) CARTONS OF COTTON SHIRTS。导入后由英文品名、包装数量及单位组合初值；组合资料不足时留空，由操作员在证书编辑页补填和审定。
- 常用中文单位由英文单位换算，例如 PCS → 件。特殊单位或换算结果不符时在程序中修改。官方申报仍需要中、英文单位。
- FOB 值独立填写，不能把 CIF/CFR 发票金额直接当成 FOB。未填表示未知，任何一行缺少 FOB 时整票 FOB 合计也留空。金额最多五位小数，保存与合计使用精确十进制。
- 英文名称和英文地址分列采集，导入后以换行组合为生产商描述。基本资料“证书生产商描述”非空时优先使用；否则组合本票引用的工厂。
- 原产标准、辅助项与子项由操作员在程序中按证种填写，普通一般原产地证、RCEP、东盟等不能共用一个必填规则。生产商保密、传真、邮箱等也按证种填写。

## 官方字段核对

依据中国国际贸易单一窗口公开的[海关原产地证书报文](https://www.singlewindow.cn/#/documentDetail?cid=COO-coo-chart&ctype=1)、页面提供的 XSD，以及[海关原产地客户端导入说明](https://www.singlewindow.cn/fs/STADOCROOT/E3/8A/47/F1601A2F6D4DC7B3C3B9C1DE52.docx)。这里区分申报所需信息和证书票面栏目，XSD 的 minOccurs=0 不代表业务申报可省略。

| 模板信息 | 官方字段 | 字符上限与要求 |
| --- | --- | --- |
| 生产企业中文名称 | Goods/PrdcEtpsName | 400；生产企业申报名称，业务申报必填 |
| 组织机构代码 | Goods/CiqRegNo | 10；业务申报必填，按官方备案填写，不直接写 18 位信用代码，不自动截取 |
| 联系人 | Goods/PrdcEtpsConcEr | 20；业务申报必填 |
| 联系电话 | Goods/PrdcEtpsTel | 20；业务申报必填 |
| 英文名称、英文地址 | Producer | 1000；官方合并为生产商描述，模板分列方便填写 |
| 生产商电话／传真／邮箱 | ProducerTel/Fax/Email | 各 50；条件字段，与生产企业联系人电话分别保存 |
| 中、英文单位 | GoodsUnit/GoodsUnitE | 各 20；官方说明均为业务申报必填 |
| 商品原产国 | GoodsOriginCountry/En | 代码 3、英文 80；适用 RCEP 商品资料 |

表头 Producer 适用 A/GE/N/L/R/P/F/K/EC/SE/MV 等证种；EC 且第三方发票标志为 1 时有必填要求。商品 Producer 及 ProducerSertFlag 适用海峡 H 和 RCEP RC。英文生产商描述不等同于国内生产企业联系人登记信息，模板同时保留两类资料。

这是资料采集模板；签证机构、申报单位、操作卡、第三方发票、补发／更改、展览等低频业务在程序编辑页核对补齐。通过 Excel 导入不代表已经通过官方签发校验。

## 导入、保存与权限

先填写资料编号，选择 Excel，核对商品、工厂、联系人和 FOB 预览，再点击“创建申报资料”。宽窗口将资料编号、文件与识别方式同排，下载与创建按钮同排；窄窗口自动换行。预览每页 50 行，可翻页核对全部商品。资料编号以页面输入值为准。预览仅存在内存；创建后保存独立来源快照，不创建发票，也不自动写入客户、出口商或生产企业档案。ACD 与 COO 从来源生成各自草稿。

单一窗口下载需要单一窗口操作和文件任务查看／操作权限；发票目录下载需要 Excel 操作和文件任务查看／操作权限。网页使用账号下载票据，桌面选择实际保存位置。切换客户端、撤销权限或离开界面后，旧请求与保存对话框不得继续下载或回写。

接受 .xlsx、.xlsm、.xltx、.xltm、.xls，非空且不超过 25 MiB，最多 64 个工作表；宏不执行。错误单元格、缺少模板工作表、重复工厂编号、找不到关联工厂、非法日期或 FOB 数值会报错。编号、HS 编码、组织机构代码和电话使用文本，保留前导零；数量与金额填写数字，日期用 YYYY-MM-DD。

公式须在 Excel 完成计算并保存。程序读取缓存结果，不运行任意工作簿公式。模板不预填真实企业或虚构的业务数据。

## 发票模板与其他客户格式

发票模板保留“明细单”、第 18–19 行双语表头、第 20 行商品起点以及六个合计公式。A1 为出口商中文名称；B3/B4:B7 为英文名称／地址；B8/B9:B12 为收货人；B13/B14:B17 为通知人；O3:O17 为日期、信用代码、合同／发票、银行、币种和运输字段。美化不改变这些坐标，原有发票导入和托单输出继续使用同一映射。

报关模板普通抬头行 16 磅、商品行 17 磅；仅冻结前 2 行，滚动时抬头和商品表头可移出视口，不再固定占住 19 行。列宽按完整 A:X 范围压缩，保持字号可读；大段地址仍可分四行填写。

英文单位、中文单位、箱数单位及每箱毛净重表头使用共享最小字号 9 磅并取消换行；英文标注为 Unit EN、Unit CN、Pkg unit、G.W./CTN、N.W./CTN，订单号简写为 PO No.。业务输入格字号保持不变。

其他客户格式复用现有识别器，选择最高置信度商品表，不自动拼接工作表。未识别的产地证专属资料须在编辑页补录；不根据出口商推定生产企业。普通发票来源仅在价格条款为 FOB 时可以带入发票金额作为初始 FOB，其他条款留空。

特殊格式可在系统设置 → Excel 导入 → 高级导入方案中保存工作表、明细范围、表头坐标及商品列。列从 A=1 开始，不用的列填 0，结束行 0 表示有效末尾；最多 10000 行、128 列。每次在页面显式选择方案。内置产地证三表模板使用智能识别，切换方案会清除旧预览。

## 实现与验证入口

布局定义为 Resources/ExcelTemplates/single-window-coo-layout.json；排版维护在 scripts/lib/excel-template-layout.mjs，由维护环境注入电子表格工具运行，不进入应用运行依赖。两份模板共用色板与排版常量，色值读取前端正式 tokens。原生模板通过明确布局建立映射，商品计算继续复用 export-doc-excel，复用已解码的商品工作表；COO 补充 DTO 来自原生 API 契约。Engine 保存授权来源快照，Domain 校验长度、十进制、商品对齐并组合草稿，沿用 schema 17。

回归入口：export-doc-excel 单元测试、crates/export-doc-engine/tests/single_window_excel.rs、scripts/test_single_window_workspace_ui.mjs 与 scripts/test_native_desktop_editions.mjs。本批实际执行情况见[模板与依赖稳定性记录](./2026-11-12模板与依赖稳定性修复记录.md)。
