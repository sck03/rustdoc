# 2026-11-25 工厂付款单与备份恢复操作说明

## 实施范围

- 付款业务信息改为最多四项独立货物明细，每项分别保存品名、数量和单位，沿用共享表格、输入样式、按钮及当前草稿／权限／版本边界。数量保持文本精度，不经过浮点转换。
- 单行付款内容在保存时归入同一明细模型；空数组默认值不会丢弃原单行内容。删除全部明细时清空旧单行字段，回读不会重新出现已删除内容。未修改发票商品数据。
- 原生契约增加可选 goodsItems 与 ApiPaymentGoodsItem，生成 OpenAPI、运行契约及 Rust/React DTO；冻结契约回归独立声明新增字段，端点、认证、权限、错误和容量元数据保留。
- 增加默认 factory_payment_template.dtpl，竖向 A4 白底两联：②财务付款、③核算。两联读取同一笔付款。标题后显示小字“（出口贸易专用）”，右侧日期使用年月日，取消 NO. 单号。货物名称、数量、贸易方式和退税率的内容区取消内部横线。
- 使用现行可编辑 V3 网格、字段、单元格边框和勾选项，字段目录提供四项货物、日期和标题；没有另一套票面或隐藏排版属性。原付款单、费用报销模板继续保留。
- 更新项目程序操作说明 Markdown/PDF 及服务器恢复指南，明确五个备份页签、完整包与数据库快照、自动执行前提、异机副本状态、新服务器导入、离线维护和恢复验收。说明按源码及界面核对，不代表本次执行了真实服务器恢复。
- 手册生成器支持指定单本、代码块与先生成再替换 PDF；文件被阅读器占用时保留完整暂存结果和原文件。用户关闭阅读器后已更新原 PDF。

没有升级依赖、改变数据库 schema 18 或其 SQL 基线；不恢复旧数据库兼容链。调度和异机上传实现未变，实际部署的备份计划由管理员按手册配置。
