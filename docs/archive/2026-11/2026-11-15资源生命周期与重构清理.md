# 2026-11-15 资源生命周期与重构清理

基于 `cd1fc0fe` 实施此前审查发现的问题。维持 Tauri 2 / React 19 / Rust、桌面 SQLite 和团队 PostgreSQL 18 的模块边界；本批不改变数据库 schema、模型指纹、API 契约或依赖版本。Windows 复用已锁定的 windows crate，显式启用文件句柄查询能力。

## 实施

1. 审批 ZIP 的完整写入链使用 RuntimePaths 磁盘预算，序号目录保留原始长文件名，取消与异常释放匿名文件。
2. 回收在短写锁内核对引用并认领对象，慢物理删除在写锁外进行；活动上传与同对象回收互斥。原有意图/无引用元数据承担重试依据，避免引入另一套数据库状态或兼容层。
3. 模板、模板包、支持包、图片下载统一在读取/压缩前预留工作集，响应持有结果实际分配容量，删除重复附件与 OA 下载适配。
4. 本地对象校验结果最多 1024 条，按打开句柄身份和变更戳复用；Windows API 留在路径平台边界。显式完整性检查继续重算摘要。
5. S3 同对象冷缓存共用有界准入与通知等待，失败、超时、取消释放协调；缓存文件缺失或变更失效。复用现有 OperationLock，不持全局锁进行网络传输。
6. 共享轮询策略接受业务正常间隔，覆盖任务、备份、审批材料、人事、核验、维护、汇率和待办。临时错误恢复，永久错误停止；原有终态、后台页与分页规则保留。没有新增 UI 文案、样式体系或持久化状态。

源码规模基线仅按相对 `cd1fc0fe` 的实测净变化前移：Web +8、Rust 生产 +320、Rust 测试/示例 +197、自动化 +64 行；每文件上限及原增长余量保持不变。新增状态、句柄校验和并发协调分别封装，删除无调用图片下载包装与重复下载入口；发票报表验证复用现有隔离宿主解析器。

- React 生产构建、无障碍、198 个缩放场景、84 个视觉基线通过。真实 QueryObserver 验证首次临时失败恢复、业务正常频率、终态和权限错误停止，以及卸载后定时器清理。
- 设置/任务生命周期 18 场景、汇率 7 场景、模板草稿 26 场景和模板命令 21 场景通过。汇率旧测试的普通 Error 改为模拟 fetch 网络故障的 TypeError，并验证退避期间没有请求；没有放宽生产错误分类。
- 脚本套件、59 处 GitHub action 引用、Tauri updater 合同、公开源码和源码规模门禁通过。依赖治理为 840 个组件，`unresolved=0`、`disallowed=0`。
- `cargo fmt --all --check`、`cargo test --locked --workspace`（90 组、614 passed、0 failed、7 ignored，含 13 组 doc-test）、`cargo check --locked --workspace --all-features` 通过。最后删除无调用包装后，4 项下载回归、格式及全部 feature 检查再次通过。
- 文件存储真实 HTTP/React 回归通过：附件分页、Range、本地/S3 迁移、凭据更新与授权、1440/390 布局。发票图片保存回读、真实 PDF 七页分页、越界 400、预览版本冲突 409、匿名 401 及首屏页图检查通过；宿主与 React 均来自本批源码，PDFium 等受管资源复用已核验包。
- OA 八个验证入口通过，覆盖六种申请主流程、审批与办理、材料权限、集成、高级和自定义流程。
- 本批源码构建的 Full SQLite Release 测试包通过 Windows Tauri 验收，覆盖 OCR、表格编辑、设计器、附件版本、权限、备份维护和正常退出；生成 16 份实际 PDF，人工抽查表格、PDF 预览与附件版本截图。未逐页人工审阅全部 PDF。桌面依赖检查确认 Tauri 2.12.5、437 个运行依赖，包含 SQLite，排除 PostgreSQL 服务端适配器，Domain 依赖边界通过。

- 1 GiB + 17 字节的流式密封备份与 ZIP64 专项通过，Release 实际运行 37.49 秒。工作区默认忽略的 7 项测试至此均已在对应环境单独执行通过；默认运行中的 `ignored` 没有被当作通过证据。

慢 S3 删除回归首次运行缺少测试记录的 ownerUserId，触发 SQLite NOT NULL 约束；补全夹具身份后专项通过，同时保留错误详情和并发保存断言。生产数据库约束及超时未放宽。

OA 人事附件旧回归仍断言 20 份封顶，与当前分页档案不符；改为使用独立样本验证第 21 份上传、按文件身份移除并重新上传，保留版本刷新验证，避免把重复文件的幂等响应误当成新增。没有恢复旧容量限制。

## 空间与交付

初始只读盘点：默认候选生成物约 59,628.0 MiB，其中 Rust target 约 59,324.7 MiB。清理计划位于受忽略的 `artifacts/resource-lifecycle-final/cleanup-plan.json`，按精确绝对路径列出旧测试包、隔离 PostgreSQL 集群、界面截图/数据和旧测试程序；删除前核对来源、进程、链接、Git 边界与快照。首轮已删除 55 个目标、9,778 个文件，逻辑长度 4,501,707,495 字节（约 4.19 GiB）；当段磁盘可用空间净增 3,371,331,584 字节，期间 PostgreSQL Release 编译仍在写入，不能将净变化等同于这些文件实际释放的物理块。444 个备份/私有补丁及保留包 41 个文件的 SHA-256 复核通过。可复用依赖、浏览器、原生资源和编译缓存保留。

所有 Cargo 编译、测试和 doc-test 结束后，定向清理累计达到 63 个目标；另按 Cargo 测试指纹清理 164 个测试可执行文件及附属文件，未删除 library/incremental 缓存。合计删除 13,575 个文件、16,355,461,409 字节逻辑长度（约 15.23 GiB），从首轮删除前到最后删除后，E 盘可用空间由 102,024,241,152 增至 110,644,973,568 字节，净增约 8.03 GiB。逻辑长度与磁盘净增分别记录；后者含期间编译、测试与临时文件回收的影响。最终 485 个受保护文件再次逐一通过 SHA-256 核对，清理计划无剩余目标，`git diff --check` 通过。当前验收 JSON、必要截图/PDF 和日志保留在 `artifacts/resource-lifecycle-final`，旧截图日志、已完成用途的测试包和两个隔离 PostgreSQL 集群已移除。

保留 `artifacts/resource-lifecycle-desktop/ExportDocManager.Tauri.Full` 作为本机验收程序。构建时 44 个文件、438,598,508 字节；成功创建 WebView 后，程序按既有启动逻辑清除 3 份 WebView2 安装资源、214,826,198 字节，剩余 41 个文件、223,772,310 字节（约 213.4 MiB），主程序 89,861,632 字节。41 份剩余文件逐一与构建快照核对。此目录为已运行的本机测试包，新设备离线交付应通过构建脚本重新组装安装资源；上述启动清理不计入本批定向清理的回收量。

## 验收边界

本机验证为 Windows x64；浏览器视口配置不等于其它 OS 真机。厂商 S3、Docker、Linux/macOS/ARM64、系统 IME 候选窗、实体打印和正式升级仍需相应环境验收。缓存优化不代表跨平台性能或长期生产容量已经测量。
