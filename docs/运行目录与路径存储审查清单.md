# 运行目录与路径存储审查清单

> 2026-10-27 按 Rust 源码核对路径、输出恢复与桌面迁移边界。旧 C# IAppPathProvider、sidecar 端点文件和 Config/appsettings.json 描述不作为当前存储事实。

## 当前路径

| 内容 | 位置与规则 |
| --- | --- |
| 程序根 | 启动组合根显式注入 AppRoot，资源只读 |
| 数据根 | 显式 DataRoot；便携模式使用包旁 App_Data |
| 安装版数据根配置 | RuntimeConfigRoot/runtime-paths.json 与 .bak；配置根默认为 AppRoot/RuntimeConfig，迁移提交后两份配置均指向已验证的新根 |
| SQLite 业务库 | DataRoot/Database/exportdoc-native.db；WAL、SHM、回滚日志同目录；恢复包也恢复到这一位置 |
| 实例锁 | DataRoot/Locks/native-instance.lock；模板与恢复操作锁同属 Locks |
| PostgreSQL | 服务端注入连接；维护凭据与业务账号分离，不交给前端 |
| 业务记录、设置、图片、模板历史 | 当前 SQLite/PostgreSQL 业务库，不新增图片数据库或 LocalStorage |
| 内置模板 | AppRoot/Templates/Export、Internal、Office，只有 .dtpl 进入正式模板链路；OA 默认模板同时嵌入 Engine |
| OA 提交档案与 PDF | 当前业务库 oa-submission / oa-approval-pdf，历史原附件 BLOB 保留；不属于 job-output，不受任务清理影响 |
| 用户文件模板 | DataRoot/Templates；显示名称目录 report_templates.json |
| 模板存储锁 | DataRoot/Locks/report-template-storage.lock；先取文件锁，再进入数据库事务 |
| 模板事务快照 | DataRoot/Cache/TemplateTransactions；成功或完整回滚后清理，回滚失败保留 |
| 文件任务发布恢复 | 注入的 RuntimePaths.cache_root/TaskPublications；标准为 DataRoot/Cache/Native/TaskPublications；私有清单和旧文件快照保留到提交／补偿完成，默认清理器保护 |
| 运行缓存 | RuntimePaths.cache_root，标准服务根为 DataRoot/Cache/Native |
| PDF 页图预览 | 服务实例内存中最多四份、合计 64 MiB、五分钟有效的 PDF；无新默认文件目录，PDFium 仍读取 AppRoot/Resources/Pdf 的受控库 |
| 日志 | DataRoot/Logs；请求日志 requests.jsonl / requests.previous.jsonl 有界轮转，以请求编号关联处理和下载阶段，保留固定失败分类与丢弃计数，不记录原始异常、请求正文或凭据 |
| WebView profile | DataRoot/WebView；其中浏览器自身的 SQLite/LevelDB 由 WebView 管理，不是业务库，不拆散迁入 Database |
| WebView 离线安装器 | Windows 便携包 AppRoot/WebView2Runtime；预检和主窗口成功后仅清除已知安装文件及空目录，失败可重试；系统 WebView、Loader 和 profile 保留 |
| 凭据主密钥 | DataRoot/Security，按需创建并限制目录访问权限 |
| 单一窗口交接目录 | `DataRoot/SingleWindow/Clients/<ProfileKey>/coo` 或 `acd`，按需创建；配置仅允许受管根内安全相对路径 |
| 单一窗口身份/档案/词典 | 当前业务库的 settings/records；不再使用旧 station.id 或词典 override.json 文件 |
| 模板包、支持包 | DataRoot/TemplatePackages、SupportPackages，由对应任务按需创建 |
| 字体、PDFium、OCR | 受控 AppRoot 资源及中央清单声明的位置 |
| 组包资源清单 | AppRoot/exportdoc-package-files.json，仅登记程序白名单路径与摘要；退出清单的未修改资源可由打包器回收，业务目录不参与 |
| 用户导出 | 原生保存对话框/浏览器下载明确选择；服务不得暗自另建默认输出目录 |
| 桌面任务结果位置 | 保存实际所选安全绝对文件／目录路径；下载 BLOB 副本过期和删除任务记录不删除外部用户文件，打开位置再次校验现存祖先与链接边界 |
| 开发与验收 | target 为 Cargo 编译树，artifacts 为程序包/验证输出，.codex-runtime 为下载缓存/工具/临时工作区；详细清理边界见[脚本说明](../scripts/README.md#工作区清理)，均不提交 Git |

桌面仅预建 Database、Templates、Backups、Cache、Locks、WebView、Logs。没有用途的 Files、Exports、Config 不再默认创建；既有目录不自动删除。备份快照仍属于 Backups 或 DisasterRecovery，任务中间数据库属于受管 Cache，不与正在使用的业务库混放。具体子目录从各能力和打包清单解析，不把 C# 历史目录复制成 Rust 路径合同。缓存允许重建，业务库、备份、模板、资源和发布输出不能当作缓存删除。

安装版更换数据目录时，配置根的 `pending-data-root-migration.json` 记录本次源、目标及申请身份。重启后先取得源、目标各自的 `Locks/native-instance.lock`，源存在旧位置 `native-instance.lock` 时一并取得；锁路径在复制、切换和清理期间保持原位。目标根的 `.exportdoc-data-root-migration-pending.json` 保存相对路径、长度和 SHA-256 清单，`.exportdoc-data-root-migration-copy.tmp` 用于单文件受控暂存；完成提交另使用 `.exportdoc-data-root-migration-complete` 标记。复制和恢复均核对本次身份、路径与实际内容，未知或变更内容不覆盖。

清单校验完成后，源根写入 `.exportdoc-data-root-migration-redirect.json` 封存，再同步新根配置及其备份，逐个核验并删除已复制的源文件。旧根、实例锁及封存标记保留，封存后新增的未登记日志等内容也保留；不递归删除仍含打开锁句柄的旧根。普通数据库打开会拒绝未完成目标和已封存源，损坏的标记同样拒绝。安装版已保存的数据根不存在时停止启动，不重建目录和空业务库；配置回退也不能重新启用封存源。

占用、空间不足、内容冲突或中断时保留迁移现场，通过安排迁移的原程序重启续办；清理中断可以继续核验剩余源文件，已提交目标中的后续业务修改不会被旧清单覆盖。恢复前应先排除占用、连接原磁盘或另存冲突内容，不删除标记来强行打开数据库。便携版继续通过退出后复制完整程序目录迁移。

## 修改前后检查

出口商印章从用户显式选择的安全绝对路径有界读取，完整校验 PNG/JPEG、扩展名、5 MiB 和像素限制；阻塞读取在工作线程执行，原始字节直接上传到既有图片存储，不创建默认图片目录。维护测试夹具先释放数据库和锁再删除隔离根，失败明确报告；这一清理机制不适用于业务目录。

普通文件任务的结果 BLOB 与历史分别保留，容量回收只处理既有业务库中 `job-output` 的受控结果；不清理业务附件、备份仓库、主密钥或模板。下载的 128 MiB 实例预算只约束内容分配，不新增磁盘缓存目录；受管备份继续使用原流式文件边界。参数及保留规则见脚本说明。

单文件发布在私有恢复目录保留旧普通文件的摘要和必要快照，已有目标超过 64 MiB 时要求选择新文件名。多文件目录先在用户选定父目录的本次 `.exportdoc-batch-<任务编号>` 暂存，提交后去除临时身份标记。恢复按业务库状态保留已提交结果或撤回本次输出，只逐个处理身份、文件名和摘要匹配的文件；未知／变更内容及提交状态不明的清单保留并停止继续办理。清理中断可在重启后继续，取消不会跳过必要补偿，不递归删除用户选择的目录。

备份与恢复使用 DataRoot/Backups/PostgreSQL、Backups/ServerMigration、Backups/ScheduledRecovery 和 DisasterRecovery。日常仓库有独立身份标记及逐包清单，保留策略只清理已登记且摘要匹配的文件。待恢复目录、恢复日志及原文件快照保留在对应受管根内，含密钥或明文数据库的目录复用私有 ACL／0700。流式上传及打包中间文件位于受管 Cache／本次工作目录，失败清理本次暂存；恢复现场和正式包不当作可重建缓存删除。PostgreSQL 恢复仍取得独立实例锁，存在未完成恢复时普通启动拒绝连接业务库。

1. 由 RuntimePaths/平台适配器注入路径，业务规则不自行读取宿主环境或全局静态路径。
2. 检查绝对路径、受管根、全部现存祖先、symlink/junction/reparse point、父目录可写性；拒绝路径穿越与磁盘根。
3. 业务引用保存相对路径或受控 ID。文件名使用 NFC 和共同非法字符/设备名/尾部点空格规则，最多 180 个 Unicode 字符，同时不超过 255 个 UTF-8 字节和 255 个 UTF-16 单元；PDF 建议名在扩展名前按相同预算截断。
4. Windows 比较遵守不区分大小写；Linux/macOS 尊重目标卷语义，不能把不同文件折叠成一个。
5. 写入使用同目录临时文件和原子替换；失败/取消清理临时输出，保留原数据及需要人工恢复的快照。
6. 数据库、文件和外部工具失败不返回成功空列表。共享文件与数据库变更的锁顺序固定，版本冲突保留草稿。
7. 测试使用隔离 DataRoot；跨平台编译不能替代链接、取消、真实文件对话框和目录迁移的运行验收。

## 清理

先运行 `scripts/clean-generated-artifacts.ps1 -ListOnly` 盘点，再按仓库 AGENTS.md 的边界清理。默认保留依赖缓存、浏览器资源、业务数据与交付输出；扩大清理范围必须符合用户授权。文档整理不是删除运行数据的授权。

当前实现和平台限制见[架构事实](./当前架构事实.md)与[平台矩阵](./多平台与多架构支持矩阵.md)。
