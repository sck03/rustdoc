# 单一窗口 Excel 导入说明

适用：当前 React／Tauri 单一窗口的“申报资料”入口。推荐先点击 **下载 Excel 模板**，填写后上传、核对预览，再创建申报资料。桌面选择保存位置，网页通过当前账号的下载票据获取文件；下载模板需要单一窗口操作及文件任务查看、操作权限，导入预览本身不需要文件任务权限。

## 模板结构

使用模板的“明细单”，保留第 18–19 行中英文表头，从第 20 行开始填写，一行一个商品款式。不要合并商品行或移动表头、表头上方字段及列的位置；行数不够时在合计行前插入商品行。默认智能识别会核对标准模板结构后使用固定坐标；全局自定义映射不会自动干扰导入或托单导出。

| 位置 | 内容 |
| --- | --- |
| A1 | 出口商中文名称 |
| B3、B4–B7 | 出口商英文名称、地址 |
| B8、B9–B12 | 收货人英文名称、地址 |
| B13、B14–B17 | 通知人、地址 |
| O3–O9 | 发票日期、信用代码、合同号、信用证号、银行、币种、发票号 |
| O10–O17 | 监管方式、付款方式、运输方式、装运日期、贸易条款、装运港、目的港、目的国 |

| 商品列 | 内容 |
| --- | --- |
| A、B、C | 唛头、订单号、款号 |
| D、E、F、G | 英文品名、面料成分、中文品名、品牌 |
| H、I | HS 编码、原产地 |
| J、K、L | 数量、英文单位、中文单位 |
| M、N | 箱数、箱单位 |
| O、P、Q、R | 长／宽／高（厘米）、体积 |
| S、T、U、V | 每箱毛重、总毛重、每箱净重、总净重 |
| W、X | 单价、金额 |

至少填写款号或中英文品名之一，并填写有效数量。HS 编码、款号、订单号和证件编号使用文本，保留前导零；数量、箱数、重量、体积、单价和金额填写数字，不把单位拼进数值。日期推荐 `YYYY-MM-DD`。空白模板没有商品，直接导入会提示没有有效明细，这是正常校验。

使用公式时，须在 Excel 中完成计算并保存，使文件包含计算结果。程序读取缓存值，不执行任意 Excel 公式；缺失缓存值可能导致该字段为空或该行不能导入。

## 识别范围与申报填充

允许 `.xlsx`、`.xlsm`、`.xltx`、`.xltm`、`.xls`，上传非空且不超过 25 MiB，工作簿最多 64 个工作表。所选工作表有效内容不得超出 10000 行／128 列，业务商品最多 5000 行。宏不执行。

其他客户格式可以尝试表头识别，但并非任意布局都能准确导入：多工作表会选择识别置信度最高的商品表，不自动拼接各表。使用下载模板最可靠；预览用于核对，不直接写入发票或申报。

点击“创建申报资料”后保存独立来源快照，资料编号以页面输入值为准。代理委托和产地证以该快照生成基础草稿，再分别保存自己的编辑内容。品名、HS 编码、数量、金额、重量、收发货人等用于相应默认字段；不是所有 Excel 列都有同名申报字段。

证书类型、原产地标准、生产商、签证机构、报关与申报单位代码、操作卡、官方代码选项等须在编辑页核对补录。产地证的收货人和特殊品名可独立修改。导入成功不等于已通过海关业务校验，仍须完成编辑页校验和提交包检查。

## 特殊客户格式的手动兜底

智能识别不适配时，在系统设置 → Excel 导入 → **高级导入方案**中填写方案名、准确工作表名称、明细起止行、表头单元格和商品列，点击“保存方案”后保存系统设置。明细结束行 `0` 表示自动到有效末尾；不用的商品列填 `0`，不用的表头坐标留空。至少映射数量，以及款号或品名。列号从 A=1 开始，不能超出 128；行号不能超出 10000。

每次在发票目录的“特殊格式 Excel 导入”或单一窗口申报资料的“Excel 识别方式”选择 **手动：方案名**，再选择文件。手动方案直接读取指定表、范围和列，不要求智能识别先找到表头，也不会自动回退或从补充表填回已关闭的列。工作表名称不匹配、方案缺失或坐标错误会报错；切换单一窗口方案会清除旧预览，须重新选择文件。

默认仍为“智能识别”，方案不写入浏览器持久化。管理员维护的方案保存在当前业务数据库中，所有使用者按当前权限读取；方案只描述布局，不保存客户工作簿内容。

## 实现与验证入口

模板导出与一般 Excel 工具复用 `export-doc-excel` 和 Engine 文件任务；单一窗口不复制第二套表头识别器。新增下载／另存接口由原生契约生成，需要单一窗口操作、文件任务查看和操作权限，不需要发票或 Excel 工具模块权限；任务创建前即检查这些权限。

`crates/export-doc-engine/tests/single_window_excel.rs` 验证模板导出、独立权限、固定映射及 ACD／COO 来源填充；`scripts/test_single_window_workspace_ui.mjs` 验证下载和页面取消；`scripts/lib/native-single-window.mjs` 验证 Windows Tauri 实际按钮、文件输出与申报界面。执行结果见本批稳定性记录。
