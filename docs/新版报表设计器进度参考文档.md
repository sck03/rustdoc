# 可视化模板设计器

> 2026-10-24。本文件名保留以维持入口，内容只描述当前 React + Rust 设计器。票面验收见[PDF 方案](./Rust统一V3模板与原版PDF验收方案.md)。

## 编辑与输出

### 明细打印方式的选择

保留两种内容来源，共用一套商品数据、明细表、合计、分页和 PDF 输出。自动组合适合常规制单：按模板组合品名、订单号、款号等字段，修改商品资料后自动更新；录入行适合客户指定顺序、共同品名、任意说明或留白，打印描述可以独立于商品资料保存。强制全部改为录入行会增加普通单据的重复维护；全部自动组合则不能完整表达自由排版。无需新增模板格式或复制两套报表实现。

| 需要 | 建议方式 | 内容在哪里维护 |
| --- | --- | --- |
| 常规逐件输出，商品资料更新后同步打印 | 商品资料自动组合 | 商品资料 + 模板的明细列/组合排版 |
| 一个品名对应几行数量、穿插说明、保留原文和空行 | 按录入行打印 | 打印排版 + 同一模板的录入说明列 |

在商品明细顶部的“明细打印方式”选择，选择后打开对应编辑视图，随发票保存。商品资料/打印排版按钮只切换编辑视图；切换打印方式保留两边已有内容。内置发票和装箱单接收录入行，内置合同与报关单继续使用商品资料。自定义模板是否接收录入行由其说明列设置决定，不按模板名称判断。

### 按录入行打印

选择“按录入行打印”后进入“打印排版”。每个货项保留一条数量金额行，在其上下可插入任意文字说明和空白行，编辑多行文字、上移/下移、删除说明或空白、重置该货项排版，并支持撤销/重做。数量行的描述可刻意留空；可以在上方只写一次共同品名，下方保留不同数量和箱数。款号、订单号或其他说明都只是普通文字，没有固定组合或专用票面。

共用品名时，先选数量行，点击“描述移为上方说明”：原文连同换行移到上方，数量行描述清空，数值不变，整步可撤销。后续数量行描述可以留空。删除说明/空白行直接在常用工具栏办理；删除整件商品仍在“行与货项操作”，避免把删除说明误当删除业务数据。

打印排版内可直接新增、复制、删除和移动货项，整体操作会带上其说明与空白行。说明和空白行可以跨相邻货项移动；数量金额行始终与原商品数据对应，跨货项排序使用“上移货项／下移货项”。批量插入支持一行一条任意说明，中间和末尾空行均保留，一次插入可一步撤销。Ctrl/Cmd + Enter 在当前行下插入说明，Alt + 上下方向键移动当前行，Ctrl/Cmd + Z 撤销；中文组词期间不触发这些快捷键。插入和移动后焦点跟随目标，翻页选择该页第一行；撤销或删除缩短明细后自动选取仍存在的行，页码随选择同步。

“录入显示列”可选择重量、体积、商品属性和备用字段等现有商品列；显示顺序按选择顺序追加，打印列和宽度仍在模板设计器中调整。数量、箱数、单位、单价、金额和其它商品字段与商品资料同步；打印描述单独保存，刻意留空时不会被品名补回。未自定义排版时描述跟随英文品名，“重置本货项排版”恢复此默认并可撤销。两种编辑视图首次访问才挂载，切换保留显示列、批量说明草稿和选择，打印行每页最多挂载 50 行。

说明和空白不参与合计；空白行在输出中保留实际高度。一个货项最多 64 条打印行，一张单据最多 10000 条，每行文字最多 1000 字。只有说明而没有任何商品资料或数量的空货项会阻止保存并提示补充，避免静默丢失排版。

内置发票和装箱单已指定说明列。自定义明细表在属性顶部选择“按录入行打印的说明列”，文字在该列输出，其他列继续绑定数量金额等字段。未指定时始终使用商品资料；已指定且单据选择录入行时使用录入原文。同一模板可以保留自动分组及小计，它们只用于商品资料自动组合；录入行模式保留作者顺序，不重复生成分组标题和小计。修改字体、列宽、边框继续使用原设计器；录入表不是整张打印票面的所见即所得画布，应通过预览核对最终分页。文字行和空白行均参与分页。

从空白设计两种明细：选择主体图层 → 添加“明细表” → 在“明细列”增删列、绑定字段、设置标题/宽度 → 在描述列的“组合排版”安排自动组合内容 → 在属性顶部指定同一列为录入说明列。切换“画布示例”观察两种排列；示例只影响编辑显示，实际打印仍由当前单据决定。最后在“说明与合计”配置合计/金额调整/首页说明，在“分页与高级”配置侧栏、分页及商品资料分组。选择不接收录入行时，示例同步显示商品资料；不会出现选择框显示录入行而画布显示商品资料的矛盾。

从空白设计仅使用商品资料的模板（例如合同、报关单）：添加明细表后，将“按录入行打印的说明列”保持为“仅使用商品资料”，再配置字段组合与样式。同一张单据即使选择了录入行，该模板仍按商品资料输出。这个能力由明细表配置决定，与模板名称或是否由默认模板复制无关；一份模板只能输出一张启用的明细表，第二张插入/复制会保留原稿并提示。

两种打印方式共用同一份明细表列设置：可以新增、在前方插入、复制、删除、重排，以及修改标题、商品字段、组合片段、打印宽度、字体和边框。“画布示例”在商品资料和录入行之间切换，说明与空白、数量金额的位置直接可见；切换只影响本次编辑会话。点击画布中的列会同步属性栏的选择，选列不写入模板或增加撤销记录。录入说明列在属性顶部更换，调整金额引用在“说明与合计”更换，然后才能删除该列。

“打印宽度(mm)”与上方列宽条使用实际打印尺寸，侧栏按毫米保留，商品列分配剩余宽度。修改一列时只与相邻列交换空间，到达最小宽度时停止；新增/删除列后按比例显示实际宽度。“等分列宽”与这些操作统一放在“明细列”，原“表格样式”中的比例参考宽度控件已移除。旧的“明细区参考宽度”没有对应 Rust 输出效果，已移除。窄列可能让标题、数字与单位换行，应通过真实预览选择合适宽度。

报表管理在 `#/reports/templates/manage`，设计在 `#/reports/templates`。文件、个人及共享模板共用目录选择；设计器负责画布、预览与保存。六类内置模板都可以打开，修改内置内容创建 DataRoot 下的副本。

唯一文件格式为 `.dtpl`，内部 schema 版本 3；界面不把版本号当作产品名称。API 传递可编辑 JSON，磁盘容器带长度及 SHA-256 校验。没有高级 HTML、V2 转换或任意脚本/CSS 入口。

参考[锐浪官方报表设计说明](https://www.rubylong.cn/gridreport/fun-design.htm)的样本修改、直接编辑、拖放和撤销方式，入口提供可展开的三步指引：选内容、调排版、预览并保存。继续使用本项目 React/Rust 排版与 `.dtpl`，未引入商业报表引擎。

2026-10-05 再次核对上述锐浪说明及[帆软 FineReport 官方产品说明](https://www.finereport.com/product/)。锐浪的“在样本上修改、即时编辑、拖放、撤销”适合本项目日常单证；帆软的类 Excel 单元格合并、对齐与扩展适合现有高级表格。借鉴交互方式，不复制其代码、图标或商业引擎，也不将 SQL、数据连接、公式编程和 BI 配置交给普通制单用户。当前使用六份内置样本、中文字段和自由画布，常用表格可直接添加，分组等进阶设置默认收起；不增加第二种模板格式或第二套排版器。

搜索无结果时显示“没有找到匹配字段”，可一键清空并继续输入。点击、拖放和工具栏插入共用目标图层、容量与商品排版检查；失败明确提示并保留草稿，粘贴冲突整批拒绝。自由商品字段和高级明细表的互斥在两个方向都生效，不必等到保存时才发现无法输出。页眉“仅首页输出”、页脚“跟随正文”可单独修改并撤销，改名、显隐等其它图层操作保留这些打印设置。

“图层”面板可搜索已放置的标题、中文字段、字段路径，查找重叠或隐藏内容。高度和打印行为收进“图层设置”，切换资源页签保留搜索与展开状态。画布上方独立显示各图层名称、角色、数量及隐藏/锁定状态，颜色与画布边界对应；点击定位实际设计带，仅滚动画布，不把工具栏卷出窗口。选中内容同时显示在固定字号的提示栏。

画布表格外框不增加额外内边距或占位边框，表头网格按模板宽度显示并与独立商品竖线对齐。缩放、选中和“组件边界”只改变编辑提示，不改变打印几何或已正确的 PDF 线条。

元素列表只在图层面板可见且对应列表展开时渲染；收起和切换页签保留搜索、选择与展开状态。大型模板的隐藏列表不再生成全部元素按钮，多选计数使用同一份选择集合。

默认“适合宽度”（最高 100%），优先保证编辑可读性；“适合窗口”查看整页，手动缩放不被窗口变化覆盖。“组件边界”可开关，不进入模板或影响打印；缩放手柄保持屏幕尺寸并位于组件外侧，短字段中心仍可拖动。文本限制在组件范围内，选中表格的手柄不再被裁剪。

移动、尺寸、图层高度及列宽拖动共用指针会话，松开时按最终位置提交一次。Esc、失焦、画布实际滚动、窗口变化或离开设计器会取消未提交的拖动，并释放动画帧、指针捕获和监听器；拖动中撤销恢复撤销后的当前位置。右键不启动缩放，第二个指针不覆盖进行中的同类拖动；未改变尺寸不增加撤销步骤。

栏位按设计器自身可用宽度调整；空间不足时属性栏移到下方，避免应用主导航占宽后仍挤成三栏。更小屏幕继续使用面板切换。

工具栏“多选”支持逐个点击选中/取消，触屏无需 Ctrl 键；选中后统一对齐、分布和大小，一步撤销。普通拖动已选元素时保留整组选区。小屏通过“添加内容 / 画布 / 属性”切换面板，保留同一编辑实例、草稿和选择；权限仍由服务端与模板状态控制。视图变化不发布草稿，文档只在修改后序列化一次。

新建模板和六份默认模板仍以 **A4** 为默认纸张。“页面设置”可直接打开纸张、字体和页边距；需要其它票据时可选 A3、A5、Letter、Legal 或自定义 40–600 mm 宽高，精确到 0.01 mm。修改自定义宽高同步方向，切换方向交换宽高，可撤销；标准尺寸来自 Rust/OpenAPI 的同一份定义，保存、画布、续页与 PDF 使用实际宽高。错误的纸张名称/方向/尺寸组合、没有可打印区域的页边距会被拒绝。

内部坐标为 1/100 mm。Header、Body、Footer、Overlay 图层共享文字、字段、图片、线条、矩形和页码组件；Flow 支持普通行、固定网格、条件、循环明细及分页符。前端维护编辑结构，Rust 负责正式测量、分页和 SVG/PDF 输出。页面字体为 6–48 pt，独立组件为 5–48 pt；画布不能接受正式输出不支持的 96 pt 字号。

## 从空白重建内置样式

当前六份默认模板使用的组件、字段与打印属性均有可视化入口。进入模板管理的“我的 / 共享模板”，填写名称并选择“新建空白模板”，再进入设计器即可自行组合；默认模板提供现成排版参考。可以直接设置表格行列数，再合并、绑定字段和调整样式，无需编写 JSON、HTML、SQL 或脚本。报关单的复杂合并格、合同续页及末页位置仍需手工排版并核对输出。

能力与验收分开记录：六模板重建回归从空文档调用编辑模型、录入参考属性并比较完整打印结构及原生输出；这不等于通过鼠标逐格完整重画了六张票面。真实界面另验证空白网格、明细表、合并、字段、条件、图层、撤销、保存回读及 PDF。本批实跑结果见进度文档，不将历史测试或模型重建夸大为全部人工操作验收。

设计组件按内容、样式、布局组织；右侧属性取消常驻说明段落，保留字段名称、当前状态及操作失败提示。侧栏、固定表格、条件内容、明细列和分组不依赖内置模板名称，可以组合其他单证/付款报表。当前可绑定的数据仍是已授权的单证和付款报销两个数据域，并非连接任意数据库的通用 BI 工具；扩展新业务数据源应通过字段契约及服务端授权，不能在画布中直接加入 SQL。

新建模板初始带一行可编辑标题；需要完全空白的画布时，选中标题并删除，再选择主体图层添加内容。

| 默认票面 | 主要表格尺寸（行 × 列） | 从空白组合的主要内容 |
| --- | --- | --- |
| 发票 | 自动明细表 5 列，另加唛头侧栏 | 页眉抬头、组合商品列、可选金额调整、仅首页唛头、末页合计及跟随正文的条件条款/签章 |
| 装箱单 | 自动明细表 6 列，另加唛头侧栏 | 组合商品列、首页唛头、末页合计、边框延伸与跟随正文的签章 |
| 合同 | 明细 4 列；交货 2 × 4、条款 1 × 1、付款 1 × 1、签字 1 × 2 | 首页抬头、自动明细表、交货/付款条款与签字网格、末页签章；默认不含特殊条款 |
| 报关单 | 票头 7 × 15、申报区 3 × 15；明细 9 列 | A4 横版、合并网格、组合明细列、首页/续页行数、仅首页申报区与报关章 |
| 付款单 | 主表 5 × 7、签字 1 × 3 | 合并网格、竖排文字、字段与前标签、支付方式勾选组、独立单元格边框 |
| 费用报销单 | 主表 5 × 9、签字 1 × 3 | 网格费用列、斜线表头、人民币大写及金额字段、合并备注和签字栏 |

新插入的普通表格默认为没有业务内容的空白网格，在“整张表 → 表格结构”设置行数、列数；“快速版式”仍可选择现有组合。调整尺寸保留范围内的内容、行高、样式和合并，新增格沿用整表外观；缩减会移除超出部分，可一步撤销。合并可以覆盖整行，拆分保留原格内容和文字/边框样式。列宽按现有宽度重新分配并留出新增列空间，最低 1%，可按毫米或百分比输入（百分比六位小数），载入时保留已有列宽精度，总和保持 100%。

工具栏和组件面板直接提供普通表格及商品明细表。多列行从两个等宽空白文本栏开始；明细表从常用商品列开始，不自动添加唛头、地址或标题。需要侧栏时，在“分页与高级 → 侧栏”添加，再选择任意合法的单据字段或固定内容；内置模板的已有侧栏与用户保存的设计保持原样。

明细列标题和跨列表头支持多行文字，例如先写“数量”，换行后写“Quantity”。Ctrl/⌘+Enter 或移开焦点提交，Esc 取消；也可直接双击画布上的列标题编辑。修改只改变标题，字段绑定、列宽和合计不变，一次撤销恢复整个标题。

默认发票在首页金额列表头下方、首条商品上方靠右显示“贸易条款”字段的原文，例如 `FOB SHANGHAI`；该行下方不画横线，保留表头、外框和金额列竖线。在发票“运输与报关 → 运输与条款”填写贸易条款；报表不会自动拼接装运港。从空白重建时，在明细表“说明与合计 → 首页说明行”添加一行，清空标签，选择金额列并绑定“贸易条款 (Trade Terms)”，本行文字设为靠右，在“本行文字与边框”关闭下边。该行只在首页输出，可同样配置其他单据字段或固定说明。

多列行也只编辑当前选择的列，固定文字支持换行，样式和边框按需展开。修改文字、字段或样式保留各列原宽；拖动边界或直接输入宽度只调整相邻两列，总宽保持 100%。列数遵守每列至少 1% 的布局约束，输入过程中不批量创建组件，避免极大数值让编辑器卡住；新增列为空白内容。

在“整张表 → 表格结构”可于当前格的上方/下方插入行、左侧/右侧插入列，也可删除当前行或列。跨越该行列的合并区域会相应扩大或缩小；删除合并格起始行列时仍保留剩余区域的内容，删除独立格则移除其内容，可撤销恢复。此操作适用于任意普通网格，不依赖默认模板名称或预设尺寸。

“单元格位置”一次输入目标位置，例如 `D4` 或 `4,4`（第 4 行、第 4 列），按 Enter 定位；支持中文逗号，超出当前表格范围会提示并保留选区。一次定位同时确定行列，避免在合并表头内逐项输入时被中间位置截住。“上一格 / 下一格”顺序移动，按钮上的方向键按相邻位置移动；合并格显示左上角，也可直接单击画布。切换单元格/整张表页签保留选区；属性面板不再额外渲染一整套单元格按钮，大网格定位不发布文档草稿。

复制或粘贴整张表格会重新分配组件、行、列、单元格与组合片段的标识，同时更新合计/说明/小计的列引用，避免画布复制成功却在保存时被 Rust 判为重复。固定文字、表格内容、绑定与样式保持；没有修改的样式继续在内存中共享。

直接输入 X/Y 或执行对齐时保留当前打印图层，避免首页唛头、末页合计等内容被自动改成另一种打印行为。跨区拖动仍自动更新区域，也可通过“所在区域”显式切换。商品循环和分页符继续受主体区域约束。

单元格的“业务字段”和“判断字段”从当前模板数据域的中文目录选择。勾选项每行填写“名称=值”，例如“电汇=电汇”；Enter 换行，Ctrl/⌘+Enter 或移开焦点提交，Esc 取消。前标签、斜线文字和勾选项在完成编辑后只形成一次撤销记录，输入过程中保留换行及等号。

把左侧普通字段拖到画布现有格内可直接绑定，保留该格的尺寸、文字样式和边框；拖入勾选组时保留选项。重复绑定同一字段不增加撤销步骤。锁定或隐藏表格不能修改，商品字段拖入固定格时明确提示使用独立商品字段或循环明细表。固定网格、多列行、条件内容、侧栏及说明/合计行仅选择单据级字段；普通明细列选择商品字段，组合片段可使用当前授权域内的合法字段。

普通表格、多列行等正文在首页保留首组件的设计纵坐标，空页眉也遵守上边距。后续内容按间距排列并受下边距/页脚限制，换页后从正文上沿继续；所设位置无法容纳组件时提示调整位置或高度。因而从空白设置的表格位置会进入真实预览和 PDF。

“图层 → 新增图层”可添加同类图层，分别设置每页重复、仅首页或末页跟随正文。图层可以改名、上下调整顺序并撤销；删除只处理空图层，保留必要的主体和覆盖层，锁定图层不能被排序或删除。印章仍通过受控业务图片字段或资源绑定，尺寸和位置自行设置。

锁定也保护图层的设计区高度。同类可见图层中存在锁定层时，共用的画布分隔线暂停调整；解锁后再拖动，避免只改变一部分图层。单层高度输入遵守同一锁定规则。

页面可选默认字体和字号；普通文字、字段和页码可选字体及垂直对齐，表格的“字体与颜色”分区可选择黑体、宋体或沿用页面字体，并设置文字颜色。常用色板提供黑色，旧模板未显式设置的颜色继续沿用原默认值。单元格的字号/加粗仍在内容属性中设置，“文字间距”支持上、右、下、左四边。线宽支持小数，切换实线/虚线保留原宽度；普通表格的“整张表 → 精确列宽”可输入百分比，差额由相邻列承担，保持整表宽度。

完成后保存为自己的模板，用相同业务数据检查单页、续页、末页、长文本和空值预览，再检查 PDF。模型回归从空白逐组件插入六份完整默认模板，设置图层、坐标、合并格、行高、列宽与全部打印属性，并比较实际堆叠顺序；界面回归另验证空白设计、输入、复制、撤销和保存回读。真实 Rust 输出对照见本批进度，模型重建不冒充逐张人工点击重绘或实体打印验收。

设计器可组合现有授权字段设计检查记录、收据、清单及其它固定/循环报表，无需以某个默认模板为前提。业务数据源仍为 ExportDocument 与 PaymentVoucher 两个授权域；页面、模板和字段能力的通用性不表示接入了任意外部数据库。

## 区域选择与批量编辑

选中普通表格后展开“从表格粘贴文字”，把 Excel 或其他表格复制的矩形区域粘贴到输入框，点击“填入表格”。从当前格向右、向下填入，需要时扩展表格；保留文字样式和边框，一次撤销恢复。支持制表符、单元格内换行和双引号，不执行公式、HTML 或脚本；公式只能粘贴其复制得到的文本。

遇到多份文字落入同一合并格，或目标含业务字段、勾选组、斜线表头时，整批拒绝并说明原因，原模板不变。可先拆分或选择普通文本区域再操作。每批最多 10000 格，行列数仍受原网格约束；输入过程中不重建网格或序列化整份草稿。适用于收据、登记表、检查表等通用排版，不依赖六份默认模板名称。

默认费用报销单的“报销净额”与“小计”位于同一行，中间不显示竖向分隔线。

工具栏直接提供“普通表格”，插入后是空白网格。在“单元格位置”输入 `A1:C3` 可选择矩形区域，也可先单击起始格，再 Shift+单击终点格，或在导航按钮上用 Shift+方向键扩展。选区自动完整包含接触的合并格，画布直接高亮，不重新生成表格或增加撤销记录。

“合并所选区域”一次完成多行多列合并。唯一一份内容即使原来不在左上角也会保留；存在多份文字、字段、勾选项、斜线文字或备用内容时，提示先整理内容并保留原稿。向右/向下合并遵守相同规则，不再静默丢弃被覆盖格。选中区域中的合并格也可以一次拆分。

选择多个格后可统一字号、对齐、加粗和四边文字间距，只有本次修改的属性会应用到各格，其余样式与字段保持。还可设置全部框线、仅外框或清除框线；颜色及粗细取起始格，未配置可见线型时采用实线。共享边同步相邻格，避免清除后仍被相邻边框补画。上述操作均可一步撤销，适用于任意普通网格。

按用户 2026-10-12 明确要求，数据源继续保持单证与付款报销两个授权域。本轮完善通用排版和操作，不增加外部数据连接或第二套报表运行时。

## 表格与分页

2026-10-15 集中检查商品明细组件：商品列、表格样式和分页面板首次访问才创建，组合排版、跨列表头、分组及合计编辑器首次展开才创建；已经访问的编辑器保留实例，返回时保留选择和草稿。字段目录和选项按数据源复用。明细标题、侧栏文字/宽度和可选打印行数在完成输入后一次提交，清空行数恢复自动分页；不再每输入一个字符就序列化整份模板。

新增、复制和导入统一限制为 100 列，复制保留独立的条件与边框，等宽分配保持参考总宽度。跨列表头在 Rust 输出中按实际跨列宽度测量并重复；说明行、合计与分组小计按合并范围排版，采用首末列的外侧边框，空白内容不额外撑高。表格延长时只延长空白区和外框，不重新穿过合并单元格画竖线。分组键为空也有独立小计，分组标题按“与后续明细靠拢”与首条商品一起分页。

说明及合计行未设置水平对齐时，沿用对应列的对齐方式；合并标签沿用首列。默认发票、装箱单、合同的 `TOTAL:` 保持左对齐，数量与金额继续按各自列对齐。显式设置的行样式仍然优先，画布和 Rust PDF 使用同一规则。

原生输出始终按完整商品行分页，单行超过一页会提示调整列宽或字号；移除没有实际效果的“明细行避免截断”切换控件，旧模板中的对应属性仍保留读写。这里的通用性指现有单证/付款数据域内的自由排版，不表示任意外部数据源或无限高度的单元格可以跨页拆分。

常规设计使用独立商品字段：左侧分为“普通字段”和“商品明细字段”，把中文字段名称拖到纸上，各字段分别移动或缩放，键盘微调、吸附和撤销照常生效。画布只显示一件商品的设计行，上下虚线表示重复范围；正式输出按相同列位逐件重复。选中商品字段可直接修改位置、大小、字号、对齐和最小行距，标签、颜色/边框、旋转和输出等低频设置折叠。长内容撑高后，同列下方字段顺延，底部对齐字段保留设计时的相对偏移。发票号、唛头等普通字段不加入商品循环。

字段、文本及页码的字体可直接选择三份随包字面：Noto Sans CJK SC 常规/粗体、Noto Serif CJK SC 常规。它们是两个家族、三份文件；选择粗体明确使用已有 Sans Bold，不引入系统字体或不存在的 Serif Bold。字体、字号和位置进入同一份模板，保存回读及撤销保留选择。

点击商品字段列表中的已有字段直接定位选中；新增字段自动寻找商品行内空位，不再堆叠到纸张右边。**自动排位只决定初始位置，不会锁定字段**：添加后仍可手动拖动、缩放、方向键微调并撤销。空间不足时保留草稿并提示调整或直接拖放。箱数、数量、金额列移动后，可点“合计与明细同列对齐”，一次调整对应合计的对齐边，并可一步撤销；不会建立永久位置绑定，合计仍是普通字段，可单独编辑。日常操作无需配置组合片段或输入坐标。

默认发票与装箱单使用同一商品明细表组件。默认发票的货名列由 36 mm 扩大为 68 mm，箱数、数量、单价和金额分别为 18、19、20、23 mm，唛头侧栏保持 32 mm。货名、PO、款号仍可自由组合和隐藏；TOTAL 与分列合计保持列对齐。默认合同仅显示货名，去掉款号片段，保留付款条件和签字。已有私人、共享及文件模板不自动转换；独立商品字段继续用于自由设计。

普通表格和条件显示可从工具栏添加，多列行、商品明细表和分页符位于“高级排版”。从空白模板可选择独立商品字段或商品明细表两种结构；需要自动列合计及多行金额调整时使用明细表。同一模板不能混用两种商品循环结构。

高级明细表按“明细列／表格样式／说明与合计／分页与高级”组织，选中表格先显示内容编辑，位置及图层输出默认收起。“明细列”只挂载当前列的编辑器，提供标题、字段、列宽、对齐和复制/删除；中文标题完成输入后一次提交，可一步撤销。“组合排版”和“跨列表头与边框”默认收起；复杂列保留中文字段显隐开关，组合排版一次编辑一个片段，支持增删、复制和移动。切换单项/组合保留原绑定和已有组合，复制列保留全部列配置以及对应的首页说明、合计和小计单元格。

“表格样式”直接选择表头或商品正文并修改字号、对齐及加粗；文字间距、边框和列宽分布分别折叠。列边框可以单独恢复沿用整表边框。录入说明列在属性顶部选择；“说明与合计”放置末页合计、金额调整及首页说明，“分页与高级”放置打印行数、侧栏、商品资料分组和小计。合计一次编辑一列，左侧合并区域中的内容显示在标签下方。页签切换保留选中项、展开状态和草稿；字段来自当前报表的中文目录并按固定/循环位置筛选。未识别绑定继续显示并允许修正，不自动替换。

- 普通网格可增删行列、合并拆分、设置列宽/行高、四边、虚线、斜线表头、竖排文字、标签位置和勾选。
- 自动明细表支持表头、组合内容、分组和汇总、唛头旁栏、首页/续页最大行数。
- 合计字段可编辑“单位/后缀”，数值继续使用原精确汇总格式。默认装箱单总毛重/净重附 KGS，总体积附 CBM；画布、保存回读和正式 PDF 使用同一配置。
- “边框延伸到表格底部”让竖线及底边至少铺满画布中设置的表格高度，并受当前页可用空间约束；拖动下边调整高度时，结构预览和 Rust 输出同步。合计行可单独设置四边与线型，或恢复沿用表格边框。默认装箱单仅保留外框与唛头分隔竖线，延伸到设计底部；货品各列不画内部竖线，合计上边使用虚线。默认发票和装箱单的右上方标签统一右移并右对齐；旧用户模板保留原设置。
- “商品之间显示横线”独立控制正文行分隔，表头、外框和合计边界保留。正文垂直对齐同时作用于单元格和分栏片段；默认发票金额与单价同一基线，装箱单箱数、数量、毛净重和体积下移到描述末行。
- 组合内容可逐段隐藏；ColumnBreak 使用递增百分比划分独立区域，长款号不能挤压箱数、数量或单价。空 PO/款号行可收起。
- 页眉/页脚可重复、仅首页、只在末页或跟随正文；页脚占位与实际输出页保持一致。内容放不下时明确提示，不静默覆盖邻格。
- “跟随正文”的页脚紧接实际明细及合计，空白填充仅决定表格边框的延伸高度；正文中排在表格之后的普通组件仍从完整表框之后开始。默认装箱单的签章采用这一规则，合同印章与末段条款分栏，下缘略触卖方签字所在行。
- 发票和装箱单每页重复抬头/表头，唛头仅首页，总计仅末页；合同续页从明细表头开始，末页接条款签字；报关单首页 6 项及申报区，续页最多 15 项并连续编号。

图层选中、锁定和隐藏会约束插入、拖动、缩放、复制、对齐和粘贴。工具不能把当前锁定图层的插入操作偷偷转移到另一层。普通坐标/样式修改和撤销使用同一状态模型，草稿比较只在文档变更时重新计算。

## 条件显示

### 商品字段的显隐与占位

独立商品字段的“显隐与空行”提供“空内容时隐藏字段”“按条件显示”和“隐藏时收起空内容行”。例如款号字段设为空时隐藏并收起；只有这一水平范围没有其它实际内容时才收起高度，避免把同一行的数量或金额一起删掉。底部对齐字段随收起后的内容上移。

“在商品末尾添加占位行”插入可移动、可调整高度的商品占位元素，每件商品重复保留该高度；它也可按条件显示。商品明细表的“组合排版”可增加固定高度占位片段、调整顺序，并为片段设置条件与空行省略。这些设置支持撤销、保存回读和 Rust 正式输出。版式空行由模板控制，发票业务明细仍保存真实商品记录。

### 多行金额调整

在发票编辑页展开“金额调整”，逐条填写说明和带符号的金额：定金等减项填负数，样品费／附加费用填正数，可同时录入多行。说明支持换行，通常未填写时不输出任何调整行。

从空白添加商品明细表，在“说明与合计 → 金额调整”启用“显示发票金额调整”，选择“说明列”和“金额列”。调整行自动放在商品之后、TOTAL 之前，TOTAL 绑定 `Invoice.AdjustedTotalAmount`。例如说明 `RECEIVED DEPOSIT`、金额 `-10963.50` 会按币种输出 `-USD10963.50`。商品金额合计仍可用 `Invoice.TotalAmount`，调整合计可用 `Invoice.AdjustmentTotalAmount`，三者不能混淆。

可以选择不输出调整行，隐藏时保留现有合计绑定；在“末页合计”可明确选择商品金额或调整后应付金额。复制列会更新关联引用，删除仍被调整行引用的列时需要先修改映射。内置发票采用同一可编辑配置，没有专用后台票面。

工具栏提供“条件显示”，左侧也可通过“组件 → 显示与隐藏 → 条件显示”添加；默认发票可直接选择合计下方的特殊条款组件。属性面板分为“显示条件”和“显示内容”，先选择字段、比较类型和判断方式，再设置需要显示的字段或固定文本。最多八条规则，选择“全部满足（并且）”或“任一满足（或者）”；增删、修改和组合方式支持撤销、保存与重开。

| 通用 | 有内容、为空；空白/null 和未勾选值视为无内容，数字 0 是有内容 |
| 文本 | 等于、不等于、包含、不包含、开头是、结尾是；可勾选忽略大小写，默认精确匹配 |
| 数字 | 等于、不等于、大于、大于或等于、小于、小于或等于；按原始精确小数比较，不使用票面舍入值，最多 28 位小数，不填写币种、单位或千位分隔符 |
| 日期 | 等于、不等于、早于、不晚于、晚于、不早于；填写有效 YYYY-MM-DD 自然日，不接受时间戳或时区转换 |

例如：币种“等于 USD”且总金额“大于 10000”时输出额外说明；特殊条款“有内容”时打印备注；某备用字段“为空”时输出固定提示。数字/日期字段未填写时，大小或等值比较不成立，需要判断缺失时选择“为空”。配置或非空业务值无法按所选类型解析时明确报错，组合规则不会掩盖错误。

条件和输出内容严格属于当前模板数据域：单证类使用 Invoice/Customer/Exporter 等，付款报销类使用 Payment/Payee；任意附加规则混用另一类字段都会被前后端拒绝。条件组件是单据级内容，不在商品循环外判断 item 字段。内容位置、字号、高度和边框沿用组件设置；隐藏时不绘制内容及边框，画布仍展示可编辑占位，实际结果以样例/当前单据的原生预览为准。

默认发票的特殊条款与签章并排放在末页合计下方，空值及只有空格/换行时不显示标题。多行内容按框宽换行，超出所设高度会报错，不能截断后继续导出。内置单证章为 56×35 mm、报关章为 61.6×35 mm；旧用户模板不自动改写尺寸或增加条款。

## 草稿与多用户

预览页可选择“矢量排版”或“实际 PDF 页图”。后者展示同一 Rust 排版生成的 PDF 经 PDFium 渲染的页面，支持上一页/下一页；重新生成默认从第一页开始。单据或模板变化后旧修订不能继续翻页，须重新预览；切换草稿、模板、单据或预览方式取消旧请求，迟到响应不回写。缺少 PDFium 时明确失败，仍可选择矢量预览，不冒充 PDF 页图。

服务端同样检查图层、元素与资源数量、主体图层和唯一编号，不能绕过页面直接写入超限模板。图片资源只接受 PNG/JPEG，ID 须匹配摘要和类型；未上传图片的草稿先补齐绑定再保存。正文规范化后最多 4 MiB，数据库和文件模板一致。模板管理页面按需下载设计器代码，现有草稿/撤销实例在设计与预览往返时保留。

草稿与撤销历史仅在页面内存。预览往返保留编辑实例；远端刷新、读取失败、保存冲突或校验失败均保留本地草稿。保存中暂停编辑，图片上传中禁止提交，离开前按脏状态确认。

连续方向键微移合为一个撤销步骤；停顿、重新选择、撤销或重做后的新移动单独记录。合并时间属于历史状态，React 重复执行状态更新也不会吞掉撤销边界；历史仍受条数及估算大小限制。

“重新载入”在存在修改时须明确确认放弃，取消保留草稿；图片上传期间禁止重新载入。状态提示区分未保存修改、上传中和与已载入模板一致，不把内存草稿显示为已保存。

模板日常流程为：选择内置或公共模板 → 填写名称并复制到“我的模板” → 打开设计器调整 → 保存 → 在单据打印或导出时选择自己的模板。保存后的私人模板仅本人可用，无需发布或共享；内部沿用 Draft/Private 状态，区别于尚未保存的页面草稿。即使管理员可以维护模板记录，也不会把他人的私人模板列入自己的输出目录。

内置原稿保持只读；公共文件模板的新建、覆盖、改名、删除、导入以及全局默认选择仅管理员可办理。普通用户即使被授予较大的发布或导入数据范围，也不能改动公共文件或全局默认。用户模板的内容和生命周期由所有者及管理员维护，不能凭公司/全局数据范围停用、归档或恢复他人的模板。

团队共享是可选流程：有发布权限时先发布，再明确选择部门、公司或全体团队范围；发布本身不自动共享。共享原稿只读，更新建议先复制、修改、预览，再发布新模板；若要修改原稿，须先明确收回共享。全局默认只允许公共文件或已发布且全体共享的数据库模板，修改、停用、归档或收回该模板前必须先更换默认，避免影响其他人的输出。停用/归档模板不进入可用目录；归档恢复及恢复历史内容形成私人模板，保留历史版本。

数据库模板命令使用 ExpectedVersion；复制和创建切换模板前确认未保存修改，冲突和失败不覆盖草稿。模板查看权限、源业务域和分享受众都必须满足；知道模板/图片 ID 不能越权读取。保存、复制和状态变更同时刷新管理目录与输出目录。

文件模板变更使用 revision 和共同存储锁，显示名称与物理文件名分别维护。模板包传递可移植的文件默认引用，数据库模板编号不跨库导出。导入失败回滚本次文件和清单，不覆盖无关设置。

图片为受控 PNG/JPEG，上传归属和内容保存在业务库中，按摘要去重。用户、数据库模板与历史、文件模板的有效引用共同决定读取和回收；仍被引用的图片不可回收，付款图片不能通过出口模板权限绕过业务域校验。

## 维护入口与验收

- 模板源：`scripts/lib/default-report-designs.mjs`；生成：`scripts/generate_default_dtpl_templates.mjs`。
- 前端：`features/report-designer`、`features/reports`；DOM/CSS 只负责交互和设计预览。
- 领域：`export-doc-domain::{designer,template}`；渲染：`export-doc-report`。
- 用例：`engine::{report_templates,report_template_files,report_assets,reports}`。

验证必须覆盖编辑后保存回读、409 草稿保留、跨用户授权、图片回收、模板包默认项、单页和多页实际 PDF。Windows 原生输入法、其它 OS/架构及打印机需要单独运行证据。未测项目保持待验，不把旧 .NET 或浏览器 HTML 结果算作 Rust PDF 通过。
