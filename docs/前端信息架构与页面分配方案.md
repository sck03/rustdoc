## 1. 结论

本节“现状”和 §2 数值保留 2026-11-03 的实施前语境。2026-11-04 的实际导航是六组，设置已收敛为六类配置并拆出备份/维护，流程管理按六分区和单定义编辑；当前页面归属、深链和测试回执见二期记录。

1. **导航总量偏大、分组逻辑混合。** 现状 7 组、39 个一级入口（含子项 44 个叶子页面）。"申请与资源"组的 7 类申请与"申请与审批"中心重复；"工作台"同时装个人事项（待办、通知、公告）和共享工具（邮件、付款打印、文件任务）。目标：6 组、33 个一级入口、39 个叶子，分组改为"我的事 / 做业务 / 行政人事 / 资料工具 / 管系统"。
2. **系统设置是三层嵌套 + 两套保存。** 左侧 8 个分类，分类内再有二级页签（单据 3、备份 4、维护 5），页签内再堆叠多块面板并嵌套折叠（设置目录内 19 处 `<details>`）；顶部"保存全部修改"作用于全部分类，而备份页又有自己的"保存灾备设置"。目标：系统设置只保留 6 个**配置**分类，**备份与恢复**、**系统维护**拆成独立页面，每屏一个任务、一条保存条。
3. **流程管理一页承载 13 个流程定义 + 日历 + 办理分工 + 审批单模板 + 代理 + 单位任务 + 异常 + 定时发布**（OA 目录内 22 处 `<details>`）。目标：定义列表 + 独立编辑屏 + 6 个分区。
4. 其余页面（发票五页签、付款四页签、组织四分区、账号与权限两页签、报表模板三页签、人员目录与详情）结构已清晰，**保留分配，只换模板与控件**。

## 3. 分组原则

1. **按"我在做什么"分组**，而不是按模块来源：我的事 → 做业务 → 行政人事 → 找资料与工具 → 管系统。
2. **每组 ≤7 个一级入口**；超出的用"一个入口 + 页内二级导航"承载（现有 `children`/`showSectionNav` 机制）。
3. **侧栏只放入口，页内放分区**：同一任务的多个视图用页内分段导航，不再逐个占侧栏。
4. **配置与操作分开**：有"保存草稿"语义的是配置页；执行备份、恢复、清理、诊断的是操作页，不共用保存条。
5. **一屏一任务**：首屏可见 ≤3 张卡片、每张卡片 ≤8 个字段；低频内容折叠但折叠内不再嵌折叠。
6. **地址即位置**：每个屏幕有自己的地址；旧地址不删，前端重定向到新地址。
7. **不改业务边界与权限键**：入口移动只改菜单归属与路由表，`moduleKey`、`requiredPermissions`、`workspaceAccess` 判定不变。

## 7. 系统设置重排（重点）

### 7.1 现状问题

- 三层嵌套：分类（左）→ 二级页签（`SettingsSectionNav`）→ 面板堆叠；备份与维护在第三层内再用 `<details>` 折叠，"高级支持与诊断"把两个分区收进折叠导航里，用户找不到入口。
- 两套保存语义同屏：顶部"保存全部修改"管整份设置（跨分类），备份页另有"保存灾备设置"；状态文案"未保存：单据设置、邮件设置"要求用户记住别的分类改了什么。
- 工具条过载：密钥开关、刷新、恢复默认、校验、保存五个控件常驻；校验结果面板只在"维护工具"分类下出现，与被校验的字段不在同一屏。
- 操作类功能混入配置：日志清理、数据归属改派、发票清理、诊断包、PostgreSQL 维护、整机迁移都是"执行动作"，却与"填写并保存"的配置共用一套布局。

### 7.2 目标结构

**系统设置（`/settings`）只保留 6 个配置分类**，左侧分类列表固定，右侧一个分类一屏：

| 分类 | 首屏卡片（≤3） | 折叠/次屏 | 保存 |
| --- | --- | --- | --- |
| 运行与数据库 | 常规与目录（通用导出目录） / 数据库连接（只读信息 + 密钥更新） / 软件更新（桌面端更新来源） | — | 分类保存条 |
| 单据设置 | 录入默认值（备用列数、空白行数） | 字段名称（三组各 10 项，按组切换）/ 申报默认值 作为二级页签保留 | 分类保存条 |
| Excel 导入 | 导入方案（方案选择 + 列映射表，固定表头） / 缺省资料 | 恢复默认映射、删除方案进卡片操作区 | 分类保存条 |
| 汇率与币制 | 来源与网址 / 获取间隔 / 常用币种管理 | 自定义来源格式说明折叠 | 分类保存条 |
| 邮件设置 | SMTP 服务器 / 发件人与默认内容 / 收件人规则 | 测试连接作为卡片操作 | 分类保存条 |
| AI 服务 | 模型地址、名称、密钥、提示词 | — | 分类保存条 |

保存模型：设置仍是一份对象、一次 `Revision` 并发保存，**但保存条只显示"本分类 N 项未保存 · 其他分类 M 项"与一个主按钮"保存全部修改"**；密钥开关只出现在含密钥的卡片内；"校验设置""恢复本分类默认""重新加载"收进保存条右侧"更多"菜单；校验结果以行内提示附在对应字段下，无法定位的汇总在分类顶部可折叠面板。

密度规则：卡片 ≤8 字段；≥1181px 两列、≤1180px 一列；说明文字 ≤1 行，长说明进"?"展开；低频字段用 `CollapsibleSection`，折叠内不再嵌折叠。

**备份与恢复（`/system/backup`）**，操作页，顶部分段导航 5 项，无全局保存条：

| 分区 | 内容 | 动作 |
| --- | --- | --- |
| 备份计划 | 日常灾备开关、周期、保留策略（折叠）、最近结果 | 保存计划 / 立即备份 |
| 异机副本 | WebDAV/S3 配置、凭据逐项开关、寻址方式（折叠） | 保存副本设置 / 测试连接 |
| 备份文件 | 本地完整备份表（时间、大小、校验、来源） | 下载 / 用于恢复 / 删除 |
| 恢复 | 从本地备份恢复、从外部包恢复、PostgreSQL 维护步骤说明（折叠） | 暂存恢复（确认文本） |
| 整机迁移 | 运行数据目录迁移（桌面）/ 完整迁移与换机（PostgreSQL） | 发起迁移（确认文本） |

任务状态条只在发起了任务的分区显示；灾备状态条固定在"备份计划"顶部。

**系统维护（`/system/maintenance`）**，操作页，分段导航 6 项：运行检查（状态摘要 + 功能依赖）、日志管理（留存规则有自己的保存按钮 + 清理）、数据归属改派、发票数据清理、问题诊断包、后台任务状态。取消"高级支持与诊断"折叠导航，技术类分区排在最后即可。
