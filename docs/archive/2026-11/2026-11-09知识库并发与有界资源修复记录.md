# 2026-11-09 知识库并发与有界资源修复记录

## 实现与职责

- HS 实例的 `versionNumber`、保存 `expectedVersion`、单删版本及批删 `{items:[{id,expectedVersion}]}` 由 Contracts 原生定义生成。服务不再用最新数据库版本覆盖请求版本；重复新建返回 409，批删先完整验证再同事务删除。知识包内部合并显式使用事务读取的版本，不增加外部旧接口兼容。
- React 实例库、实例工作区和联网候选审核从主页面拆分，复用 `useScopedSave`、草稿合并和未保存保护。保存推进版本并保留请求期间的新输入；切换、关闭、删除贯穿确认和刷新作用域。删除期间锁定字段，选中记录刷新后仍使用选择时版本。
- 联网候选编码查询在聚焦后才启用，使用编码作为共享缓存键；草稿只保存实际修改，切换列表清理。后端分批遍历并只保留目标页，批量确认使用定向税则查询，取消逐实例全量加载。
- 历史发现独立到 `hs_history`，使用授权读快照、Storage 字段投影和物理 ID 键集，每批最多 8 个文档，不复制发票明细数组。候选仍限制 2500/5000 个匹配来源，款号去重计数，样本最多 8 个；正式实例只投影指纹以排除已知候选。
- 待办取消深页前缀物化，每来源最多保留 `pageSize + 1` 条。游标绑定来源、排序键、筛选、页号和页容量；前端提供首页/上页/下页，刷新或改筛选回首页。读取继续重验当前身份和权限。
- 单一窗口派发先授权读取归档，事务外完成解码/摘要核验，再短事务重验权限、目录、版本和清单；保留派发尝试防重及并发回执终态。回执 XML/摘要/主报文核验与归档摘要计算也移到事务外，写事务继续复核绑定与业务状态。
- 文件任务发布与保留清理分离。清理按任务、输出、输入分批短事务执行，具有独立 30 秒期限；失败通过 `retentionFailure` 指标报告，已发布任务不被改成失败。发布/恢复本身失败仍关闭服务写入边界。
- 2026-11-10 集中回归暴露后台审批 PDF 在渲染繁忙超过 5 秒时失败。已接收的审批单、批量报表和单据包/邮件附件任务改为等待当前任务的执行期限和取消信号；前台预览仍使用 5 秒准入预算。共享渲染入口继续保证每进程一次重型转换，缺少后台执行期限明确拒绝。新增超过前台等待预算、执行期限及缺少作用域回归。

## 合同与性能边界

数据库维持全新 schema 16，752 个 API 操作、689 个运行 schema，无依赖升级、数据库兼容链或额外持久化缓存。生成文件从原生定义统一刷新，冻结契约只通过显式审查变更对照。

待办精确计数仍需遍历授权候选；游标不是跨页数据库快照，数据变化后应刷新首页。历史关键字不匹配时仍可能扫描较多授权记录，税则与替代关系仍有年度集合；本批降低驻留结果和重复读取，不宣称所有查询恒定时间或已完成端到端容量压测。

源码规模治理只按已审查的本批净增加更新聚合基线，单文件上限、增长额度和原剩余空间不变；并发保护与回归新增代码不能算作总代码量下降。
