# 2026-11-28 恢复契约与资源优化

本批继续全项目审查中已确认问题的实施，按用户要求只运行必要检查，随后清理失效生成物并交付 main。数据库保持 schema 19，依赖与许可证版本未变；API 调整从原生定义统一生成 Rust DTO、OpenAPI 与 React 客户端。

## 实现与职责

| 范围 | 修复与结果 | 模块边界 |
| --- | --- | --- |
| 容量策略 | 保存事务只返回 `revision` 和 `policy`；后续磁盘采样失败不会把已成功保存显示成失败。前端合并回执、保留续编并推进版本，独立刷新采样 | 原生契约新增 `ApiCapacityPolicyReceipt`；Engine 管理事务，hook 管理草稿与查询失效 |
| 备份收尾 | 有效 COMMIT 后的临时快照清理或保留策略失败，保留恢复点编号、大小和 `Partial` 状态，任务返回 `committed:true`；状态持久化失败明确返回部分提交错误，提示核对恢复点 | `scheduled/run` 集中提交后的状态处理，避免外层普通失败覆盖有效回执 |
| 便携读取 | 入口及每 64 KiB 检查取消；复用帧缓冲，索引摘要使用固定字节数组 | `portable_file` 共用分块读取，回归放在独立测试模块 |
| 仓库目录 | Directory/WebDAV 的 blob、manifest 位于 `objects/`；列表与凭证检查只枚举元数据。分区名称索引仅在受保护句柄生命周期内复用，减少重复实现和无关枚举 | `repository/names` 提供共享分区索引；适配器负责文件或远端访问，S3 保留服务端分页 |
| 维护执行 | 文件操作进入最多两个阻塞工作名额，使用契约超时；请求取消/超时后，真实 worker 结束才释放名额，避免超时请求耗尽资源 | HTTP 组合根的独立 `maintenance/execution` 承担执行调度；状态及取消保留快速内存路径 |
| 维护快照 | 启动及任务结束更新产物快照；轮询不再扫描目录。产物读取失败通过 `artifactFailure` 单独显示，保留已有快照；状态锁在写文件前释放 | Engine 管理状态与生命周期，React 展示已定义的失败信息 |
| 恢复分页 | 返回类型化 `PointPage`，额外查询一条判断下一页；支持返回首页，空页及刷新页面后仍可导航；翻页或重新解锁清空旧选择与预检结果 | Repository 生成游标，hook 管理选择和翻页状态，页面组合现有控件 |
| 凭证管理 | 计划页只用于首次设置密码，后续统一转到已有恢复凭证管理入口；明确已导出便携文件仍使用导出时的凭证；删除无消费者的 `verifyReplica` 字段 | Domain、原生契约、生成客户端、前端模型和当前测试夹具同步 |
| 集成检查 | 审批图测试补上现行 `service_id`；轻量 Rust CI 纳入该定向集成测试 | 不将完整集成、doc-test、全部 features 检查加入每次轻量路径 |

前端复用共享控件、折叠分区和现有设计令牌，没有增加第二套样式、端点或本地持久化。冻结契约夹具明确投影本批 API 变化，其余端点、认证、权限、错误及容量元数据继续对照验证。

## 格式与数据边界

恢复仓库格式提升为 **2**。目录与 WebDAV 的对象物理分区变化仅面向当前实现，旧实验仓库及含旧格式头的 `.edmpoint` 明确拒绝，不提供旧格式自动搬移或兼容链。需要新仓库时使用新的空目录或前缀；本批没有转换或删除真实备份。数据库仍只接受 schema 19，没有新增旧数据库兼容。

目录和远端操作继续校验读取保护及写入所有权，GC 实时检查读取标记。COMMIT 的现存性检查没有被永久缓存替代；对象索引有数量上限，目录写入和删除继续维持持久化与幂等规则。

## 空间清理

清理前保存精确路径及来源，检查活动进程、文件占用、目录链接、Git 边界和私有文件。只删除已核实失效的编译对象、测试程序、被替代的增量会话，以及可追溯的隔离测试数据库、截图、日志和本次 UI 测试输出。

- 已删除 361 个精确目标，累计逻辑文件体积 **5,771,556,685 字节，约 5.38 GiB**。其中首次处理隔离 `retention` 目录删除 2,007,040 字节后，Windows 报告目录非空；重新核验原清单后重试成功，重试记录另计 5,769,549,645 字节。
- 重试完成阶段实测磁盘空闲增加 **3,065,856,000 字节，约 2.86 GiB**。首次阶段未保存完整空闲差值，且构建产物存在硬链接，不将逻辑体积冒充全程物理释放量。
- 对 1,786 个保留文件复核 SHA-256，全部一致。保留现有桌面包及数据、用户/私有备份、私有工具与补丁、模板、OCR 和有效原生资源；未核实来源或用途的数据库不删除。
- 保留 Cargo/npm/浏览器/原生资源下载缓存、最新增量会话和仍有效编译产物，无需大规模重新下载。没有广泛删除整个 `target` 或 `.codex-runtime`。
