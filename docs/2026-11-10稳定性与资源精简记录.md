# 2026-11-10 稳定性与资源精简记录

本批针对单一窗口导航、操作档案并发保存、临时文件与预览生命周期、Excel 导入及已识别的模块边界实施修复。当前仅维护 schema 17 和现行 API，不增加旧库、旧接口或旧报表条件结构兼容层。

## 行为修复

- 代理委托／海关原产地证的分区导航改为按钮，展开目标所在折叠区并滚动定位；不再修改 HashRouter 使用的地址片段。
- 持卡机操作档案读取返回版本号，保存携带 `expectedVersion`。新建使用 0，旧版本保存返回 409；刷新或切换档案先处理未保存内容。保存响应明确返回本次档案标识，避免另一窗口同时新建时误选其它档案。
- 文件选择、导入、报表预览、信用证审查按当前页面／单据／客户端作用域取消，旧操作不回写新页面。短期 File、HTML 和预览结果由局部状态持有，结束后释放，不进入长期 MutationCache。
- 删除无效 `system.appName` 设置。Full 产品界面名为“业务协同平台”，Document 和 Sales 保持各自正式产品名；Full SQLite 测试包明确显示测试版身份。
- 报表条件统一为 `conditions[]`（1–8 项），删除 `condition` 与 `additionalConditions` 双结构，内置模板、设计器、Rust 渲染和回归同步更新。

## Excel 导入与模板

按用户最终选择保留手动映射，默认智能识别，每次导入可显式选择已保存方案。系统设置将方案管理折叠在“高级导入方案”，支持指定工作表、明细范围、列及抬头单元格。保存方案后还需保存系统设置。未选择方案时不读取全局草稿映射，订舱托单导出始终使用内置布局。

单一窗口“申报资料”提供“下载 Excel 模板”，网页通过受控下载任务交付，桌面通过用户选择的路径保存。创建任务前同时检查单一窗口操作、文件任务查看与操作权限，不依赖发票或 Excel 工具模块权限；模板不会带出其它模块的公司资料。导入先预览，创建后可分别填写代理委托与原产地证，不隐式建立业务发票。

模板坐标、支持格式、容量、公式与补录要求见[单一窗口 Excel 导入说明](./单一窗口Excel导入说明.md)。智能识别继续复用 `excel-analyzer-rs`，手动方案只是同一解析流程的显式坐标输入。

## 模块边界与性能

- 单一窗口页面提取档案草稿与版本、批次动作、交接包导入及对应面板；共享保存与取消边界承担请求生命周期。
- Excel 工具页面提取 `useExcelTools`，发票和单一窗口复用识别方式选择器。审批代理设置提取独立组件，草稿比较归入模型模块。
- 基础资料保存复用已有作用域保存器，移除多余 Mutation 包装；报表预览参数变化即清除旧结果。
- OA 已发布规则按标识批量读取并校验唯一性，避免目录逐项读取同一版本记录。
- 无汇总的发票复核队列，以及明确筛选的领用审批／领取队列，使用升序 ID 游标，从当前游标开始扫描；取得足够的已授权项和一条后续项后停止。状态和日期存在条件由 Storage 筛选，授权仍由 Engine 核验。日期排序及动态 OA 队列保留必要的语义扫描，不宣称所有待办已变为定长 SQL 分页。
- API 由原生定义重新生成，不手改生成文件；新增模板端点继续使用共用任务、取消、权限与重试链。

源码体积门禁按审阅后的实际净增量更新基线，保留原增长余量和单文件上限。前端生产代码净减少 164 行；新增 Rust 代码主要用于手动映射、并发与权限约束、Storage 查询及回归。Rust 测试与示例净增 285 行，自动化净增 196 行，不放宽单文件或增长限制。
